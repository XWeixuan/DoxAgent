## ONDS：减少强业务信号上的事件门槛

以无人系统、反无人系统及其工业通信市场为监测环境，而不是要求每篇新闻同时具备公司名、金额、采购或量产事实。开发时审读了漏判中的自主作战组织、无人机市场、无人平台试验、集成与拦截信息，以及模型误放的军队日常活动、普通 IT/网络安全、材料与人员训练报道。

正则首版把英文 12 组重组为 5 组：公司、旗下品牌、明确无人系统类别、自主作战/无人机型号、有限定的工业无线通信。核心产品词直接作为强信号；没有枚举所有可能事件。L1、HE 和模型定义不随正则候选变更。

模型首版用较短业务范围和最近混淆边界区分“文章属于军事机构”与“文章提供无人系统/通信市场事实”，开发误放从 19 条降为 1 条。达到调试目标后停止常规开发。首次验证漏掉反无人机研究项目和安全军事通信标准；一次额外修正尝试补全场景和研究阶段，却使开发、验证召回分别降至 71.43%、44.44%，因此按均分保留首版，未继续修改。

最终正则验证 **TP15 / FP1 / FN2 / TN62**：误放是保障设施文章中的无人机背景，漏判是 CUAS 拼写变体及军事通信升级。最终模型验证 **TP7 / FP0 / FN2 / TN29**。这些是已知剩余缺口；正则已经达标后没有根据验证坏例再加词。

## BE：实体开发与泛泛 AI/半导体扩张的边界仍未稳定

把电力供给市场、替代发电技术、储能和大型用电设施作为信息环境。早期项目、发电监管、设施开发经济性可以纳入；普通 AI 软件、芯片产品参数、设备省电宣传和泛算力融资不自动构成供电消息。不同新闻的边界仍需依冻结 GOLD 评分，疑似尺度冲突另列复核。

正则首版保留直接公司/燃料电池/电解技术信号，将电力市场、客户设施开发、晶圆厂项目分开检索。开发达到 100% / 95.65%，但验证中，“AI infrastructure + expansion/investment”收进了芯片采购、合作扩大及泛云算力活动；晶圆厂裸词、设备装机、正文产能扩张又未被覆盖，验证仅 42.86% / 33.33%。这说明开发过线不足以证明查询边界稳健。

唯一额外修正去掉泛 AI infrastructure 客户侧词，以实体数据中心/超级计算机为对象，允许正文提供实质开发事实，并将晶圆生产/制造设施与扩产活动组合。验证召回升至 100%，但准确率仅 64.29%。宽化的“wafer/fab + equipment/capacity/investment”误收了封装/成熟制程、自动化电机及 SiC 专利处置；“奈米 + 量产”也会跨题凑词。数据中心受袭报道的背景建设描述仍会命中。**额外机会已用尽，保留该版为均分最佳，不声称已解决精度问题。** 最终正则验证为 TP9 / FP5 / FN0 / TN86。

模型前三版依次尝试：明确电力/设施市场边界；增加解释和多语业务说明；缩短为清晰的市场类别及“一条实质事实即可”判据。前两版开发召回只有 58.33%、33.33%，第三版达到 84.62% / 91.67%。第三版验证仍漏掉两条晶圆制造扩产信息，TP2 / FP0 / FN2 / TN46。

唯一额外修正强调晶圆制造扩产及全文事实，确实补齐两集召回，却泛化为大量半导体研发、设备交付、封装标准、芯片采购和产业背景也相关，验证精度降至 22.22%。按四项均分选回第 3 版。此次没有证据支持“定义越详尽越好”；相近表述也可能产生很大输出差别，本轮未重复成功回答，不能把单次差异完全归因为某一个词。

## GOLD 待复核事项：没有据此改分

发现一处明确的**文档标签不一致**：旧 [80 cases A15](by-distribution-gold-review-sample-80cases-20261027.md#a15) 中，BE / `A6fab8c20d0`（Anthropic 与 SpaceX 算力合同）为 RELATED，且不在用户要求改判的 12 个案例内；当前冻结调试样本 `dev100-A6fab8c20d0-BE` 是 IRRELEVANT，理由是只有算力租赁/芯片合同、没有明确数据中心建设或供电事实。稳定 ID、标题和主体报道一致；两个资料的字段组织有所不同，不声称所有输入字节相同。

这需要单独确认新版业务尺度是否有意改变。BE 的部分产能扩张正例与“仅制造业务/设备变化”的负例也非常接近，增加调参难度。**本次全部分数严格使用冻结 GOLD，没有为了过线改标签、剔除病例或重新计算有利分数。** 后续若正式复核修订，应新建数据版本；本次看过的验证集也不能再称为未见验证集。
