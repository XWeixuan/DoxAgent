- 本轮总计 **42 个候选、84 份完整的候选×数据集结果**：正则候选判定 3,600 次、模型候选 2,400 次。另有基线正则 700、模型 350 次。真实模型文章评估合计 **2,750 次**；这是含重复候选和 INSUFFICIENT 的文章评估次数，不是独立文章数，也不冒称 HTTP 请求数。
- 遇到过少量 HTTP 429，正式重试后全部评分结果的执行错误为 **0**。没有把接口失败当作不相关，没有从分母中删除失败样本。
- 每个候选均有完整两集结果，配置及引擎指纹可比；数据集哈希与既有 manifest 一致；冻结候选未被回改；正则候选只改 L2，模型候选只改 definition；合并配置通过当前绑定语言校验。见[核验回执](../eval/distribution_relevance_tuning_remaining7_20261028/verification.json)。

## 逐 ticker 调试发现

### COHR

基线正则给强光学类别加事件要求，又缺少客户算力合同与融资主题；模型则在光子产品与近邻基础设施之间摇摆。三轮常规正则由补全主题、扩展全文，到限制泛客户背景，开发最高达到 90.48% / 100%。首次验证却只有 40% / 33.33%，暴露供电/冷却组件、封装和泛基础设施与光学市场的混淆。

一次额外修正将查询收回更稳定的光学/材料对象与实际计算资本配置，最终验证 100% / 66.67%，优于其他候选的四项均分，但仍漏 AI 投资政策、SiC 知识产权、正文资本配置和大规模算力预测。模型常规三版都未稳住边界；额外版亦未改善最终均分，选回第 2 版。其误放包括一般 AI 咨询、半导体设备厂房、内存成本融资、CPU 推理库及液冷控制芯片。

这里还存在冻结 GOLD 的同主题尺度疑点，见后文；没有据此改分或添加文章级黑名单。

### INTC

旧规则的泛 AI＋计算/电力/效率组合会放行一般安全实验和社会活动，却漏掉制造供应商、先进封装材料及实际部署。常规正则改用处理器、晶圆制造和实际计算投资等少量强业务组，第二轮开发达到 94.59% / 92.11%。首次验证召回降至 54.17%，缺口集中于制造政策、互连封装、其他语言表达与具体硬件部署。

一次额外修正补充更完整的计算制造主题，验证召回升至 87.50%，准确率 79.25%，差一点仍是未达标。剩余误放包含内存、SSD 辅助核心、功率器件及安全测试中的计算背景。

模型三轮常规最高开发召回为 78.95%；额外修正后验证达到 85.71% / 96%，但开发准确率降至 68%。最终选择额外版，却明确保留两集表现不一致的限制。

### MU

基线的 AI 硬件与能源组合产生电池储能、CPU 缓存和泛软件误放；强内存产品及具体资源架构却有漏判。常规正则用直接内存市场词、制造材料和有明确联系的客户资本配置取代大行业词组合，开发达到 93.33% / 87.50%。首次验证仅召回 43.33%，说明只覆盖开发集出现的固定短语还不够。

一次修正用更自然的市场名称覆盖制造供应、同类企业、先进封装与资源对象，最终两集过线，验证 **87.10% / 90%**。仍有“memory”用于软件内存安全、KV 缓存或消费配置的误放；组内排除不能撤销其他命中组，这是剩余误差的真实来源之一。

模型尝试范围重写、明确缩写与中文表达，增加解释并未单调改善。按均分最终保留中文第 3 版，验证 100% / 33.33%；一次额外简化虽然提高召回，却引入大量误放，未被选中。核心缺口是制造供应、客户资本配置及正文独立产业事实。

### NBIS

旧查询多重要求 AI/GPU、设施和事件共同出现，漏掉实际数据中心运营、GPU 残值、云容量预售及关键资源成本。第一轮保留直接公司/竞品/投资范围，第二轮将强市场对象扩展至全文，开发达到 96.55% / 96.55%。首次验证却只有 71.43% / 45.45%，遗漏商业托管、跨境模型部署、计算架构与信用风险。

一次额外修正按服务和实际部署对象补覆盖，最终正则验证 **81.82% / 81.82%**，两集过线。仍会把部分存储扩产、芯片供电零件当作云基础设施事实，也漏模型训练投入、硬件关键供应与部署路径。

模型按简短服务市场范围、中文范围、商业托管与融资部署边界逐轮测试，最终选额外版。开发 84.62% / 73.33%，验证 76.92% / 83.33%，未完成两集目标；主要问题仍是供应链“实际资源联系”与“供应商泛宣传”的分界。

### RKLB

旧版显式排除常规竞争任务，导致 SpaceX 日常发射、试验、卫星运营、政府采购与航天政策大量漏掉。改成少量直接航天市场对象后，正则开发达到 87.76% / 95.56%。一次验证修正去掉单独机构品牌，补足发射设施、轨道货运与航天器系统，最终验证 **90% / 90%**，两集过线。

模型第二轮采用简短空间飞行/卫星市场定义，明确常规任务、通知、图片视频和早期计划按有效事实判断，开发 83.33% / 100%，验证 **82.35% / 100%**，无需额外模型修正。剩余误放为观月科普、月面通信与月面技术征案等邻近题材，不以“航天机构发布”作为正确性证明。

### SNOW

基线正则在本调试集 8 条相关消息中一条也没召回，主要只覆盖目标公司与少数传统竞品。第一轮补企业数据管道、治理、业务数据上下文和同类平台，开发满分；首次验证召回只有 23.53%，说明稀疏正例容易造成范围过窄。

一次额外修正以企业数据平台、访问、集成、安全恢复及混合环境等稳定业务对象补范围，开发仍满分，验证 **100% / 94.12%**。没有把泛 AI 安全新闻全部放开，仍漏一条 Oracle 跨系统敏感数据访问治理报道。

模型扩展为泛企业软件后误放增多；中文第 3 版压低误放但验证召回仅 60%。一次额外扩展的数据访问/恢复定义又显著降低精度，故仍按均分选回第 3 版。模型调试只有 4 条相关 GOLD，不能从少数样本满精度推断长期稳定。

### CEG

基线正则已经在开发集过线，但存在无对象的许可/融资/燃料词和核技术跨用途误放，也漏替代发电、聚变、设施运营和电网主题。第一轮清理过度导致召回下降；第二轮恢复稳定电力对象及常见词形，用少量发电市场组加有限用途消歧，开发达到 92.68% / 100%，验证 **88.37% / 93.83%**。

模型不再要求对 CEG 的显著影响，而按发电、电力供应、运营维护和监管生命周期判断，第二轮开发达到 97.06% / 89.19%，验证 **96.97% / 84.21%**。两块均无需额外修正。剩余正则误放包括核医疗/空间同位素、消费电器与数据中心内部设备；模型仍漏部分核监管通知、人才培养和微型反应堆部署。
