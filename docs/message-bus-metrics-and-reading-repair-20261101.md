# 消息总线统计与阅读连续性修复

日期：2026-11-01。依据 `message-bus-current-metrics-and-refresh-audit-20261101.md` 实施。

## 实现口径

| 指标 | 实现 |
|---|---|
| 周期新增 | 原有正式 Stream 消息桶；按首次发布时间的业务语义日及所选周期统计。正文修订不增加新消息数，真实 0 显示 0 |
| 消息源状态 | 所有未删除绑定的总数，并区分运行、休眠、禁用、异常、未知；保留历史最近成功。IR/SEC 休市采集策略不变 |
| 正文补全成功率 | 所选周期首次观察、与当前 ticker/来源关联的唯一合格文章，当前 FULL/SHORT_FULL 数 / 总数；pending 在分母，别名去重，无样本不显示成 0%；不冒用历史网络尝试率 |
| 平均端到端耗时 | 单条新消息首次被列表发现，到首次正式发布 Stream 的时间；只纳入有可靠首次时间锚点的消息；按所选周期 sum/count，修订替换贡献而非重复累计 |
| 周期轮询覆盖率 | 每消息源最近 20 个已结算逻辑轮次的成功数 / 预期数，顶层加总分子分母。界面明示“近20轮/源”；它不随顶部日期范围改成历史覆盖率 |
| 卡片最近成功 / 当天新增 | 原采集账本当前 head / 原消息桶一次批量归并 |
| 卡片均值 / P95 | 最近 20 个逻辑轮次中、新发现并正式发布的消息 E2E 样本；P95 为真实样本排序后的 nearest-rank，不平均各轮 P95 |
| 卡片实际刷新间隔 | 最近 20 轮及其前一轮中，逻辑轮次真正完成时间的相邻差均值；失败/缺轮造成的间隔保留，不使用配置间隔冒充 |
| 卡片正文率 | 上述最近 20 轮发现的唯一文章当前 FULL/SHORT_FULL 比例，pending 保留在分母 |

逻辑轮次按源配置间隔对齐 UTC 已关闭时间槽，保留采集单元真实相位及启动 epoch。未派发的应执行轮次同样进入分母，刚启用的源只统计已产生的机会。同一必需单元内，已有账本的任一有效采集赢家证明成功；显式同组替代路径取任一赢家，互补必需单元全部完成才计该轮成功。辅助单元不冒充必需采集。Yahoo 现有三个互补 HEAD 不擅自改成替代赛马。

休市在停用时点冻结最近窗口。已有 48 小时采集明细保留不足以支持窗口时返回无样本，不编造 0/20 或复杂回填。

## 刷新与请求

- 默认一分钟只更新一份 dashboard；统计快照与消息流的 view、Query、分页状态独立。每次统计更新为一次 MINUTE context + 一次 dashboard 请求，没有逐源 HTTP 请求或默认诊断请求。
- Query key 不绑定不断变化的统计 view。刷新中和失败后保留上次成功数据，错误反馈固定高度，附请求编号，不造成布局跳闪。
- 消息流只有一个续期 owner。续期合并原阅读缓冲区、按消息 ID 保留组件，记录可见行及偏移量，恢复阅读位置；不会把已加载页替换成第一页。
- 新 view 按保留尾消息重新签发合法分页游标，避免沿用过期游标；分页期间跨 view 的旧响应不覆盖新状态。浏览器测试覆盖后续加载更多无重复/跳页。
- schema 生成显式同步 ArticleBodyCohort 依赖，修复 initial 字段导致的 500；保留严格 DTO 校验。移除失败时误显示的“旧口径”标签。

## 新增读写预算

- Bus 原 delivery 仅增加两个可空 TEXT：first_discovered_at、first_poll_due_at；初次接纳写入，同源重复输入不重写。保留规范化/别名合并中的首次锚点。第一次发布沿用已有 Stream 发布时间，不另加 publish 状态。
- 采集 head 顺带保存 epoch/间隔/版本/可选替代组；停用原 UPDATE 顺带记录 disabled_at，无额外实时事务。
- Read 只保留 delivery 的三个必要标量及已有对象元数据，不镜像 admission/worker 大文档；已有增量消息贡献增加 E2E sum/count，复用桶与索引。
- 来源定义、运行状态、来源 heads、今日计数批量读取；近20轮只对现有 cycles_unit_time 索引做有上限的区间读取，不重建整段历史。
- 卡片业务样本复用 current_source 完整来源/日/排序前缀；文章及消息按主键连接。正文顶层从已有 object_current_body_cohort 时间索引进入，再按 observation/alias 的 parent 索引匹配，默认当日请求不扫描历史 ticker 文章。
- 不新增表、索引、后台服务、定时统计任务或无限历史列表。ALL 是用户显式选择的全量文章口径，正文需读该 ticker 关联的当前文章事实；默认只读当日。
- 显式轻量迁移添加字段并刷新既有 CDC 触发器，旧休眠 head 的 disabled_at 只从已有最后 SCHEDULE 账本补一次。无历史消息或模型调用回填。

## 验证与发布边界

本地前端 67 项测试通过，typecheck 与生产构建通过。两项 Playwright 浏览器测试分别使用 1262/1559px，覆盖分钟 500、恢复、跨 14 分钟续期、SSE reset、40/60 条消息保持、展开状态、阅读位置、卡片标签对齐与水平溢出。这里是合成 API fixture 的真实浏览器测试，不等同于生产完整业务验收。

后端定向回归覆盖逻辑轮次、缺失派发、互补/替代路径、休市冻结、迁移幂等、已知零值、正文别名、首次锚点、最小 serving 字段及新 view 游标。更广回归发现备份清理/初始化旧测试失败；这些不在本轮修改范围，不宣称全仓测试全部通过。

发布以 origin/main 为唯一基线；本地其他交易执行提交和未提交修改不纳入。生产更新 API、Projector、Collector、Bus、BODY、Web；BODY 的规范化合并需传递首次锚点。Scheduler、Site Access 与浏览器身份保持原版本。正式提交、迁移结果与生产读数在部署后追加。
