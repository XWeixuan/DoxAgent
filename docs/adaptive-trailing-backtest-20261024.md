# DoxAgent 波动自适应滑动止盈回测：Case #1 / #2

日期：2026-10-24。离线研究，不修改生产交易逻辑、不提交订单。沿用[披露时点对冲研究](sector-beta-disclosure-backtest-20261024.md)的案例与 Beta，并按用户最新补充，**两例均以最早披露时点附近的有效报价假设成交，而非历史真实成交或交易意图释放时点**。

## 结论与证据等级

**这两例不支持把「40% MFE + 2.25 ATR」作为能够稳定增加净收益的生产规则。**#1 从未达到 5% 激活门槛，三种退出相同；#2 收紧版在披露后约14分钟退出，净收益低于固定退出：不对冲少赚 **$122.34**，66% Beta 对冲少赚 **$126.19**。收紧版提高了退出当时的浮盈留存比例，却放弃了后续趋势收益。

已取得真实 **5秒 BID / ASK 历史价格线**、隔夜价格线及部分逐笔 BBO，未用分钟 K 线模拟30秒确认。需要区分两层证据：

- **有逐笔复核的结果**：入场及固定退出报价；#1 不可能激活的行情上界；#2 收紧版04:54:00的退出。后者在已下载的披露后逐笔路径上重放得到相同 MFE 和退出，并额外用含 size-only 更新的完整 BBO 核实最后六次观察。
- **条件性结果**：旧版的完整持仓退出与全持仓期 MFE，采用5秒买卖价线逐时重放。价格线没有报价数量和完整刷新时间，因此无法对整个持仓期严格复核每一次“有效、未过期、数量为正”的观察。**旧版两行及相关合计不是完整报价有效性规则的最终认证结果。**没有把缺失字段伪装成真实历史数量，也没有把条件性结果称为实盘可复现收益。

仅两例、实际只有一个激活止盈的事件，无法判断稳定性、生产胜率或长期风险调整收益。此次结果更支持保留研究状态，而非直接上线收紧版。

## #1：不会激活，而非“没找到触发数据”

持仓窗口内 INTC ASK 最低 **97.67**，SOXX BID 最高 **542.42**。故即使把两个未必同时发生的最有利极值相加：

`股票毛浮盈上界 = 10000 × (101.03 − 97.67) / 101.03 = $332.57`

`66%组合毛浮盈上界 = $332.57 + 14.69329406 × (542.42 − 538.30) = $393.11`

二者均低于 $500，扣成本及有效性过滤只会进一步降低。这里的分钟买卖价极值**只用于证明达不到门槛**，没有用来生成止盈线、触发时间或精确 MFE。最终回补 INTC ask 98.58、卖出 SOXX bid 521.36，得到上表净收益。

## 顺序、过滤与数据限制

研究的具体实现选择如下；用户未指定的过滤参数在此公开，不作事后调参：

1. 每5秒观察一次；原始逐笔使用 strictly-before 时间查询。5秒价格线只在该5秒区间结束后揭示 close，不提前使用区间 high/low，也不允许一分钟收盘直接触发。
2. MFE 从假设成交后零开始，只用最近3次有效净浮盈的中位数更新，三次跨度不超过15秒。过滤单次尖峰；这是保守有效价代理，并不能保证剔除持续异常报价。
3. ATR 用已完成的1分钟有效净清算损益 OHLC 的20个真实波幅算术均值；每分钟至少6个有效5秒样本。入场前30分钟仅预热 ATR，不预热 MFE。两腿组合使用**同一时刻合计损益序列**，不把两腿各自极值拼接成组合 ATR。5秒采样的分钟 OHLC 可能漏掉5秒内波动，属于 ATR 估计精度限制。
4. MFE 达 $500，且 `MFE − max(比例×MFE, 倍数×ATR)` 为正才激活；净浮盈已扣入场佣金、预计平仓佣金及截至该时点持有成本。净止盈线只上移。对 SHORT，净浮盈跌破净止盈线等价于回补价越过对应价格线；对冲时只使用组合损益线，同步退出两腿。
5. 激活后才收集确认窗口。最近 `(t−30秒, t]` 六个5秒观察必须全部有效，至少5次越线且最新仍越线；无效观察不延长窗口。各观察按当时生效的线记录，不用新止盈线回溯改写早先越线结果。报价年龄阈值5秒，最大相对价差50bp，价格须有限、正值、不倒挂，逐笔数量须为正。
6. 完整5秒价格线没有数量、刷新时间：价格路径重放仅验证价格及价差，程序中的单位数量是显式标记的接口占位值，**不能视为历史数量通过验证**。逐笔路径另行应用完整过滤。`ignoreSize=True` 的价格变动记录会丢失数量更新，不能用其“最后价格变化年龄”直接判断完整 BBO 已过期；本轮正是用含数量更新的独立下载修正并验证04:53:45、04:53:50两次观察。
7. SMART 与 OVERNIGHT 价格线共同覆盖 #2 持仓，未在缺失区间前向填价。仅07:50–08:00 UTC（美东03:50–04:00）存在正常市场时段间隔，无观察、不退出、确认窗口清空，MFE与单向止盈线保留。[IBKR 夜盘时段说明](https://brokerage.ibkr.com/en/trading/us-overnight-trading.php)。
8. 模拟确认后按同次可平仓报价立即退出，没有额外添加订单网络延迟、排队或滑点；已包含激活后的确认等待。若要研究撮合延迟，需要另加执行模型，不能把当前结果当作实盘保证成交额。

## 证据、复现与验证

数据来自远端 `doxagent-sg` 的现有 IBKR API 会话，API服务容器内仅运行只读行情/账本查询，没有改动生产文件、配置或订单。2日5秒请求部分最初40秒超时，延长有界请求超时后已成功补齐；不是以分钟数据替换失败请求。数据抓取最大请求条数等限制见 [IBKR 历史逐笔文档](https://www.interactivebrokers.com/docs/tws-api/doc/md/historical-ticks)。

全部材料在 [eval/adaptive_trailing_backtest_20261024](../eval/adaptive_trailing_backtest_20261024/)：

- `probe.jsonl`：历史成交账本与四标的入场完整 BBO；`warmup_and_exit.jsonl`：5秒 ATR 预热与固定退出完整 BBO。
- `quote_bounds.jsonl`：#1 分钟 ASK/BID 上界证明；未参与 #2 触发。
- `five_second_quotes.jsonl`、`five_second_retry.jsonl`：SMART 四个买卖价序列，各19,812根；`overnight_quotes.jsonl`：OVERNIGHT 四序列，各5,760根，按时间过滤到本例窗口。`target_hour.jsonl`另保存22–23 UTC的独立小时请求。
- `quote_pages.jsonl`：连续下载的价格变动 BBO，股票到22:13:42 UTC、ETF到22:01:50 UTC；`confirmation_quotes.jsonl`：收紧版触发窗口的完整 BBO，包括数量变化。逐笔保留秒级原始时间，未制造毫秒精度。
- `bar_results.json`：全时段条件性重放；`partial_results.json`：逐笔覆盖范围内的重放，旧版仍明确为 `INCOMPLETE_DATA`，未冒充未触发；`bar_trace_*.csv`、`trace_*.csv`保存每5秒净浮盈/MFE/ATR/线/有效性/窗口与触发。
- `replay.py`、`bar_replay.py`：计算脚本；`test_replay.py`：6项顺序/状态检查。`manifest.json`保存输入与结果哈希。

交叉核验：排除整数秒边界难以判定顺序的样本后，5秒买卖价 close 与逐笔 as-of 快照在 **RKLB 662/662、QQQ 711/711** 个可比时点完全一致；这仅验证这些时点，不能替代整个持仓期的报价刷新与数量验证。收紧版两种仓位的逐笔重放和价格线重放在 MFE、激活与确认退出上结果一致。
