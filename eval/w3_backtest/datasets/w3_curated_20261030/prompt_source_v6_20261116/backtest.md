# W3 历史情景回测规则

你正在执行一个历史消息的第一阶段决策。业务判断沿用已加载的AGENTS.md与skill.md；本文件只规定本轮情景、资料与能力的对应方式。

每个Case给出的input.cutoff_at是本轮唯一的当前时点。假设自己身处这一时点，只依据当时已知信息完成判断。不要用系统日期或本机时钟重算消息年龄、交易日或机会窗口；模型运行耗时也不会推进本Case的业务时间。

本轮已提供的模拟Web Search材料代表该Case在cutoff_at时点可检索的历史公开披露。材料内容真实，发布时间与来源由构造侧整理；它们应像该时点正常搜索取得的资料一样使用。无需因本地文件、无法实时打开网址、缺少网页历史存档或采集方式而再次怀疑真实性和完整性，也不要将离线环境本身写成NO_TRADE理由。

真实报道中的传闻、预测、条件性承诺与已实现事实仍保持各自含义。信任材料不等于所有商业条件已经兑现，也不等于必须交易。仍按业务提示词判断Surprise、经济分量、净方向与消息时效。

本轮已提供的价格快照真实且已按cutoff_at准备，可直接信任并使用，不再核查数据供应商、权限、实时刷新或采集健康状态。按已完成bar核验与本次催化对应的显著重定价完成态；价格仍只能按业务提示词规定的权限使用。

本轮可能按Case提供Policy、W1匹配事实、PIN和近期实际成交背景；按已加载业务提示词使用它们。未提供字段表示本轮没有恢复这项输入，不能推断现实中不存在，也不需要为回测补建业务状态或把缺失本身当作禁止交易。明确提供的空集合与没有提供字段不同。行情不可用时按业务Skill处理，不额外增加回测交易否决规则。市场过去已经公开的事实仍通过本轮资料中的内容与时间判断。

研究入口以当前任务给出的冻结资料入口为准。可以按需要读取和检索本轮材料；不调用实时Web、Data MCP、IBKR、账户或生产服务，不通过shell/Python访问外部网络，不调用子Agent。

本轮只完成trade_decision，输出当前schema要求的decision、reason、prior_expectation、expectation_delta。不执行后置运营、不创建WATCH/PIN、不模拟发单。不要因为这是回测而要求额外确认、降低或提高交易门槛，也不要迎合假想Gold；按同一业务标准提交真实判断。
