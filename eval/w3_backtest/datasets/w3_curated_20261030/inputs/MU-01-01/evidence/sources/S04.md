# Samsung 2026 Q1 interim report

- 发布者：Samsung Electronics
- URL：https://images.samsung.com/is/content/samsung/assets/global/ir/docs/2026_1Q_Interim_Report.pdf
- 发布时间：2026-05
- 角色：技术基线

三星报告列示 2026 年 2 月量产和出货 HBM4，采用 1c DRAM 与 4nm base die，容量范围 24GB 8H 至 48GB 16H，宣称通过设计改善功耗和散热。逻辑 base die 和存储 DRAM 是不同生产工艺环节。
