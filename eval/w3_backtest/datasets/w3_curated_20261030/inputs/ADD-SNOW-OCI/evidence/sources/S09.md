# Oracle Announces Q1 FY2027 Results

- URL: https://investor.oracle.com/investor-news/news-details/2026/Oracle-Announces-Q1-Results-Driven-by-Triple-Digit-Growth-in-Cloud-Infrastructure-Revenues/
- Publisher: Oracle
- Published: 2026-09-10
- Role: Oracle业务规模

Oracle reported fiscal Q1 2027 cloud infrastructure revenue of $7.4 billion and cloud application revenue of $4.2 billion. Total cloud revenue was $11.6 billion. These are Oracle-wide revenues, not customer spending on Snowflake.
