# Oracle Expands Native AI and Data Services on OCI with Snowflake

- URL: https://www.marketscreener.com/news/oracle-expands-native-ai-and-data-services-on-oci-with-snowflake-ce785cdddf89f121
- Publisher: Oracle / PR Newswire
- Published: 2026-10-27T16:07:00Z
- Role: primary announcement

Snowflake AI Data Cloud will be available as a native first-party OCI service. Oracle provides purchasing, provisioning, pricing, billing and support; customers can use Oracle Universal Credits. The release discusses Oracle Fusion Cloud Applications, NetSuite, databases and reduced data movement. It does not announce a launch date, revenue amount or minimum customer spend.
Oracle says customers can use native integrations for reporting, data engineering, machine learning and AI, while maintaining access control and governance. Keeping workloads in OCI is intended to reduce cross-cloud movement and egress costs. Oracle manages pricing and discounts as well as billing; consumption can be applied against existing Universal Credits. The release does not quantify the economic split between Oracle and Snowflake.
