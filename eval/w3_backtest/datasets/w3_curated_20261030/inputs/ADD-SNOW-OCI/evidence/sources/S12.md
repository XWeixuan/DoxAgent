# Openflow Connector for Oracle general availability

- URL: https://docs.snowflake.com/en/release-notes/2026/other/2026-02-27-openflow-oracle-ga
- Publisher: Snowflake
- Published: 2026-02-27
- Role: 既有连接器与条款

Snowflake announced general availability of a connector that replicates Oracle database tables into Snowflake through change data capture on a schedule or near real time. Supported origins include OCI, on-premises and AWS RDS for Oracle. The embedded XStream license has a fee and 60-day free trial followed by an automatically starting non-cancelable 36-month billing term; an independent license option is also described.
