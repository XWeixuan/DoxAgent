# Snowflake Openflow Connector: Agentless Oracle CDC

- URL: https://www.snowflake.com/en/blog/openflow-connector-oracle/
- Publisher: Snowflake
- Published: 2026-03-04
- Role: 已有客户迁移与部署

Snowflake described its Oracle-developed agentless integration for streaming from Oracle into Snowflake. At announcement the Snowflake deployment option was available in AWS and Azure commercial regions, while BYOC was available in AWS commercial regions. This connects data to Snowflake and is distinct from a native first-party Snowflake service inside OCI.
