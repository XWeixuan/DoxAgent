# AMD and OpenAI announce strategic partnership to deploy 6 gigawatts of AMD GPUs

- 发布者：OpenAI / AMD
- URL：https://openai.com/index/openai-amd-strategic-partnership/
- 发布时间：2025-10-06（日期精度）
- 角色：加速器供应替代

## 相关内容整理

AMD 和 OpenAI 宣布跨多个 GPU 代际的 6GW 合作，首个 1GW Instinct MI450 部署预计 2026 年下半年开始。这是多年代部署安排，涉及 AMD 加速器，不能直接推导 Intel 的 CPU 数量。
