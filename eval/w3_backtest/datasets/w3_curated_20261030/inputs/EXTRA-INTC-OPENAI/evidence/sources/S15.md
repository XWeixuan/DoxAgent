# Intel Q2 2026 quarterly report: server and foundry

- 发布者：Intel / SEC
- URL：https://www.sec.gov/Archives/edgar/data/50863/000005086326000157/intc-20260627.htm
- 发布时间：2026-07-24（日期精度）
- 角色：实际服务器规模与供给

## 相关内容整理

Intel 第二季度服务器收入同比增加 20 亿美元；平均售价同比增长 48%，主要来自更高端产品组合，服务器销量同比增长 9%。公司称内部产能限制导致需求超过供给，并预计行业供应约束延续至下一年。Foundry 收入约 58 亿美元，其中 55 亿美元为分部间收入。
