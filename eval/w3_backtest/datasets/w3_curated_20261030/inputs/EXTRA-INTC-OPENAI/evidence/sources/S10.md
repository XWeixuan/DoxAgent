# Stargate advances with 4.5 GW partnership with Oracle

- 发布者：OpenAI
- URL：https://openai.com/index/stargate-advances-with-partnership-with-oracle/
- 发布时间：2025-07-22（日期精度）

## 相关内容整理

OpenAI 称与 Oracle 协议新增开发 4.5GW 美国 Stargate 数据中心；连同 Abilene 项目，超过 5GW 处于开发中。Abilene 的部分设施已开始运行，Oracle 开始交付 NVIDIA GB200 机架并运行早期训练与推理。开发中的容量不等同已投运容量，也不等同某芯片供应商收入。
