# AI Server Demand Sustains Memory Contract Price Increases in 4Q26

发布者：TrendForce  
URL：https://www.trendforce.com/presscenter/news/20260930-13258.html  
发布时间：2026-09-30  
角色：不同机构第四季度合同价格预测

TrendForce 预计 2026 年第四季度传统 DRAM 合同价环比上涨 10%–15%，NAND Flash 上涨 15%–20%；企业 SSD 因云服务商采购是预期涨幅加速的类别。它指出 AI 服务器需求强而消费需求疲弱、PC 成本上升压制终端销售；部分服务器 DRAM 供应商涨价受长期合同定价机制约束，落后市场平均。其预测与 Barron's 引述的 Circular Technologies 预测是不同研究机构和范围。
