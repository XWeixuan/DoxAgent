# Higher usage limits for Claude and a compute deal with SpaceX

- 发布者：Anthropic
- URL：https://www.anthropic.com/news/higher-limits-spacex
- 发布时间：2026-05-06
- 角色：既有 NVIDIA 算力

Anthropic 称已签约使用 SpaceX Colossus 1 全部算力，当月新增超过 300 MW、超过 220,000 NVIDIA GPU；也使用 AWS Trainium 和 Google TPU。其公告还列出了 300 亿美元 Azure 算力合作和 Google 5 GW 合作。
