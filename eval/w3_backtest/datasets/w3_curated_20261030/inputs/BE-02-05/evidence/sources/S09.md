# Oracle Jupiter permitting context

Publisher: Blockspace
URL: https://blockspace.media/insight/oracle-new-mexico-data-center/
Published: 2026-09-24
Role: project conditions

The report describes a notice for payment relief if the campus misses its 2028 opening, with Oracle remaining the main tenant. A court allowed permitting proceedings to resume without deciding whether permits should be granted. Oracle and BorderPlex said in April that up to 2.45 GW of Bloom fuel cells would replace earlier planned turbines and diesel generation; the gas pipeline had faced permit denials.
