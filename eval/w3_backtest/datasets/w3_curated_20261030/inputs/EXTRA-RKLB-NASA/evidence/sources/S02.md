# NASA Provides Update on Moon Base Rovers, Landers, Missions

- 发布者：NASA
- URL：https://www.nasa.gov/news-release/nasa-provides-update-on-moon-base-rovers-landers-missions/
- 发布时间：2026-05-26
- 角色：月球项目基线

NASA 先前公布 Moon Base I 计划使用 Blue Origin Blue Moon Mark 1；Moon Base II 计划由 Griffin 交付超过 1,100 磅货物和 Astrolab FLIP，Moon Base III 使用 Intuitive Machines Nova-C。NASA 向 Astrolab 和 Lunar Outpost 分别授予 2.19 亿和 2.20 亿美元的月面车第一阶段任务订单。
