# NASA awards four lunar deliveries

- 发布者：NASA
- URL：https://www.nasa.gov/news-release/nasa-awards-more-moon-base-science-previews-new-opportunities/
- 发布时间：2026-06-30
- 角色：既有任务订单

NASA 向 Astrobotic 授予两次交付合计 2.979 亿美元，向 Firefly 和 Intuitive Machines 分别授予 1.442 亿和 1.483 亿美元，目标 2028 年末执行月面交付。此为现有 CLPS 任务订单。
