# Higher usage limits for Claude and a compute deal with SpaceX

- 发布者：Anthropic
- URL：https://www.anthropic.com/news/higher-limits-spacex
- 发布时间：2026-05-06
- 角色：先前部署与客户

Anthropic 宣布签约使用 SpaceX Colossus 1 全部计算能力，预计当月获得超过 300 MW、逾 220,000 NVIDIA GPU 的新容量；并列举 AWS 最多 5 GW、Google 与 Broadcom 5 GW 及 Microsoft/NVIDIA 合作的 300 亿美元 Azure 容量。Anthropic 称模型运行于 AWS Trainium、Google TPU 和 NVIDIA GPU。
