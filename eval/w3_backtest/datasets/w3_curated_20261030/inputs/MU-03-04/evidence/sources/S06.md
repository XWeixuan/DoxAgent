# Memory price surge begins to cool as consumers hit affordability limit

发布者：Tom's Hardware / TrendForce  
URL：https://www.tomshardware.com/pc-components/ram/memory-price-surge-begins-to-cool-as-consumers-hit-affordability-limit-ai-demand-still-keeps-dram-and-nand-prices-climbing-through-q3-2026  
发布时间：2026-07-04T11:47:34Z  
角色：此前合同价格与反向需求

TrendForce 当时预计 2026 年第三季度传统 DRAM 合同价环比上升 13%–18%，NAND 合同价上升 10%–15%，仍上涨但较第二季度约 60% 的快速上涨放缓。报道认为消费电子厂商承受价格上涨的能力减弱，服务器需求与长约仍影响供给和价格。行业合同价、不同季度和 Micron 实现 ASP 不可直接当作同一指标。
