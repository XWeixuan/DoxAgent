# Classiq platform integrated with Amazon Braket

- URL: https://www.classiq.io/insights/explore
- Publisher: Classiq
- Published: 2022-06-02
- Role: 多硬件渠道

Classiq announced its algorithm design platform on Amazon Braket. Developers use a functional model and specify constraints, then can execute resulting circuits on hardware accessed through Braket. The release described an unnamed defense contractor developing radar optimization algorithms. Braket offers access to different quantum hardware and simulators.
