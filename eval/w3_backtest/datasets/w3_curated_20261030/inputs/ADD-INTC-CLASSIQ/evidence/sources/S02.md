# Classiq raises $110 million Series C

- URL: https://www.classiq.io/insights/classiq-raises-110m-in-largest-ever-quantum-software-funding-round
- 发布方: Classiq
- 发布时间: 2025-05-12
- 角色: 先前融资与软件业务

Classiq称由Entrée Capital领投1.1亿美元C轮，累计融资1.73亿美元；资金用于扩大销售、客户支持和研发。公司称客户数量和收入同比增至三倍，服务数十家企业团队和数百个学术机构。
