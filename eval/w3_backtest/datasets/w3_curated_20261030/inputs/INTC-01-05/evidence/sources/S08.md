# Intel says something has to give with memory prices

发布者：Tom's Hardware  
URL：https://www.tomshardware.com/pc-components/cpus/intel-says-something-has-to-give-with-memory-prices-company-says-it-will-continue-to-make-sure-that-there-are-products-which-can-take-care-of-older-memory-technologies  
发布时间：2026-06-02T09:30:00Z  
角色：Intel 面对内存价格的产品措施

Intel 客户端产品管理高级总监 Nish Neelalojanan 在 Computex 谈到内存成本压力。公司继续提供支持 DDR4 的桌面和移动 Raptor Lake 产品，在旧内存可获得且便宜时保留选择；同时为 Wildcat Lake 验证较低内存配置，起点为 8GB。受访者称 CPU 已不是系统价格的唯一决定因素。
