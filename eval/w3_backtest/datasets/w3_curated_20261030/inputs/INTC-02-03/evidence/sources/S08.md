# AMD Financial Results Second Quarter 2026

发布者：AMD  
URL：https://ir.amd.com/financial-information/sec-filings/content/0000002488-26-000121/attachments/AMD%20Q2%202026%20Earnings%20Slides%20FINAL.pdf  
发布时间：2026-08-04  
角色：竞争对手业务规模

AMD 披露第二季度数据中心收入 67.18 亿美元，同比增长 107%，环比增长 16%；该业务增长来自 EPYC 处理器需求和 Instinct GPU 放量，因此不能把整个数据中心增幅当成服务器 CPU 增幅。公司列示推出第六代 EPYC、Instinct MI450 和 Helios 机架，并称 Microsoft 扩大合作，在 Azure 规模部署 Helios 与第六代 EPYC。
