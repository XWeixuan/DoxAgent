# Intel reportedly set to hike CPU prices by 10%

发布者：Tom's Hardware  
URL：https://www.tomshardware.com/pc-components/cpus/intel-reportedly-set-to-hike-cpu-prices-by-10-percent-ahead-of-major-annual-product-launch-in-march-2027-report-says-amd-will-follow-up-between-june-and-july  
发布时间：2026-09-08  
角色：此前价格报道与产品计划

文章引述 DigiTimes 供应链来源称 Intel 预计将提高 CPU 价格约 10%，此前第一季度及七月已对部分服务器和客户端产品提价。报道明确称来源未指明此次涨价覆盖何种产品；文章推测移动与服务器可能先于桌面。另据行业来源，Intel 计划在 2027 年 3 月推出主要年度产品，AMD 于 6 至 7 月推出自己的产品。报道将这些产品发布时间与涨价报道分述。
