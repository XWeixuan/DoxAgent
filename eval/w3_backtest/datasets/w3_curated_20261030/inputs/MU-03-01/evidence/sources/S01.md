# AI server demand sustains 4Q26 memory prices

Publisher: TrendForce
URL: https://www.trendforce.com/presscenter/news/20260930-13258.html
Published: 2026-09-30T15:52:15+08:00
Role: event disclosure

TrendForce forecast conventional DRAM contract prices up 10–15% quarter on quarter and NAND up 15–20% in Q4 2026. It expected enterprise SSD to be the only category with accelerating increases, forecasting enterprise SSD bit demand above 80% year on year in 2026. It cited constrained server DRAM, CPU availability and allocated supply, while high component costs, client inventories and weak smartphones restrained consumer purchases. Some long-term contracts cause suppliers to lag market-average increases; much incremental enterprise SSD capacity was already committed.
