# Server CPU Shipments Projected to Grow Over 40% YoY in 2027

- 发布者：TrendForce
- URL：https://www.trendforce.com/presscenter/news/20261022-13279.html
- 发布时间：2026-10-22（日期精度）
- 角色：行业预测与竞争

## 相关内容整理

TrendForce 预计服务器 CPU 出货量 2026 年同比增长 31%，2027 年增长超过 40%；推理和智能体工作负载可能提高 CPU 相对 GPU/ASIC 的配置比例。其称 Intel 新产品工艺和封装问题导致出货延迟，既有 Emerald Rapids、Granite Rapids 仍为主力，内部产能限制订单履行。其估计 AMD 2026 年份额约 27%，Arm 2026 年超过 20%、2027 年约 30%；这些均为研究机构估计或预测。
