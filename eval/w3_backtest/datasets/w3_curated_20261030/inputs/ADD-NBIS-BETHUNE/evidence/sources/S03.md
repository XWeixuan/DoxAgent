# Nebius plans 240 MW data centre near Lille

- 发布方: Reuters / Boursorama
- 发布时间: 2026-02-12
- 角色: 原计划与对照

Reuters援引Nebius称改造旧Bridgestone工厂，满建容量240MW，首批容量预期夏末上线、2026年底约一半可运营；当时财务条款未披露，Reuters称该规模需数十亿欧元投资。
