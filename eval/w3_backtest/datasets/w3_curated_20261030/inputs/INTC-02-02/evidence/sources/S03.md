# Desktop CPU shipments crater 20% amid high component costs

发布者：Tom's Hardware / Mercury Research  
URL：https://www.tomshardware.com/pc-components/cpus/desktop-cpu-shipments-crater-20-percent-amid-high-component-costs-but-amd-gains-record-share-despite-ugly-desktop-processor-market-intel-floods-laptop-market-with-millions-of-cpus-but-amd-still-sets-all-time-share-records  
发布时间：2026-08-22  
角色：CPU 量与份额基线

报道 Mercury 估计第二季度桌面 CPU 出货同比下降逾 20%，组件价格高与图形卡受限压制需求；AMD 桌面单位份额为 34.9%，Intel 为 65.1%，AMD 的份额增长部分来自降幅小于 Intel。Intel 在移动 CPU 增加数百万单位供应，缩小供需缺口，AMD 移动单位份额仍升至 28.9%。广义服务器 CPU 单位份额 AMD 为 34.5%、Intel 65.5%，去年同期分别为 27.3% 和 72.7%；若仅比较 EPYC 与 Xeon 服务器处理器，AMD 份额为 46.4%。口径不同，不应混同。
