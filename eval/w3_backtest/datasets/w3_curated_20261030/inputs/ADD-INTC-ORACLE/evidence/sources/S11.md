# AMD grabs more CPU share while server shipments grow

- URL: https://www.theregister.com/systems/2026/08/21/amd-grabs-more-cpu-share-while-pricier-pcs-punish-desktop-demand/5291053
- Publisher: The Register
- Published: 2026-08-21T15:05:00Z
- Role: 服务器竞争与份额

Mercury Research estimated Q2 server processor shipments rose 20% year over year, with AMD at 34.5% of the broader server processor category versus 27.3% a year earlier. Limiting the comparison to Xeon SP and EPYC made AMD’s estimated share 46.4%. The broader category and narrower CPU comparison use different denominators; neither establishes Oracle-specific allocations.
