# Generative AI inference using OCI Compute with Intel Xeon

- URL: https://blogs.oracle.com/cloud-infrastructure/gen-ai-inference-workloads-compute-intel-xeon-cpu
- Publisher: Oracle
- Published: 2024-10-03
- Role: 既有AI推理合作

Oracle and Intel described jointly validated generative AI inference on existing OCI Compute shapes using Xeon. They noted that throughput, latency, tokens, concurrent users, batch size and model size affect sizing, and mapped representative workloads to CPU instance options. This establishes a prior CPU-inference pathway before planned X14.
