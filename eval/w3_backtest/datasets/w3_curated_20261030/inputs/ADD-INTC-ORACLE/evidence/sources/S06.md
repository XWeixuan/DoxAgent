# Oracle launches OCI Compute E6 Standard Instances

- URL: https://blogs.oracle.com/cloud-infrastructure/oci-launches-e6-standard-compute-powered-by-amd
- Publisher: Oracle
- Published: 2025-03-31
- Role: 竞争架构

Oracle announced general availability of E6 Standard bare-metal and flexible virtual machines using fifth-generation AMD EPYC. Oracle reported up to twice E5 performance at the same price. The service provides an existing AMD option alongside Intel and Arm offerings.
