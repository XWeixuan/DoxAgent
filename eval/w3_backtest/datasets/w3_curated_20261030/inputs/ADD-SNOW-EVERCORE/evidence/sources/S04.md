# Snowflake Expands AWS Collaboration with $6B Commitment

- URL: https://press.aboutamazon.com/2026/5/snowflake-expands-aws-collaboration-with-6b-commitment-to-accelerate-enterprise-agentic-ai-adoption
- Publisher: Amazon
- Published: 2026-05-27
- Role: cloud economics

Snowflake committed to spend $6 billion on AWS over five years. The partners reported over $7 billion of lifetime Snowflake sales through AWS Marketplace. The commitment is Snowflake infrastructure spending, not a $6 billion customer order.
