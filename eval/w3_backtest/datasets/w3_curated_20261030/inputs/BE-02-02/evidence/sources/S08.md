# Oracle Cites Force Majeure to Shield Itself on Data Center

发布者：Bloomberg  
URL：https://news.bloomberglaw.com/privacy-and-data-security/oracle-cites-force-majeure-to-shield-itself-on-big-data-center  
发布时间：2026-09-24T16:50:00Z  
角色：原发报道与合同条款

Bloomberg 引述知情人士称 Oracle 寻求在 Jupiter 未按计划于 2028 年上线时推迟付款，而非退出主要租户。若双方同意发生与供电承诺相关的不可抗力事件，一名知情人士称租金可推迟三年；Oracle 仍需在期间支付其他费用，付款开始后仍欠整个租期的租金。Oracle 称通知本身不建立项目延迟或改变交付预期；Blue Owl 称项目财务承诺不变。

Bloomberg 另据知情人士称项目相关债务低于面值 90 美分交易，约 20 家银行提供 180 亿美元建设贷款；一名知情人士称通知不构成融资协议下的违约事件。
