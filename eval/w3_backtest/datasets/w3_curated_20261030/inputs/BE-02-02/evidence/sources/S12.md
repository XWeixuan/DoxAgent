# STACK Infrastructure Delivers Digital Infrastructure for Data Center Campus in New Mexico

发布者：STACK Infrastructure  
URL：https://www.stackinfra.com/wp-content/uploads/2025/09/PR-STACK-Infrastructure-Delivers-Digital-Infrastructure-for-Data-Center-Campus-in-New-Mexico.pdf  
发布时间：2025-09-26  
角色：项目开发与参与方

STACK 宣布将为新墨西哥州 Stargate 园区交付数字基础设施，该项目属于 Oracle 至多 4.5 GW 新增 Stargate 容量承诺的一部分，拟提供超过 1 GW AI 负载容量并采用现场微电网。STACK 称项目由 Blue Owl 管理的基金投资；BorderPlex 主席在公告中谈及微电网设计。
