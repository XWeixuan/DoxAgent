# How Industry Collaboration Fosters NVIDIA Co-Packaged Optics

- URL: https://developer.nvidia.com/blog/how-industry-collaboration-fosters-nvidia-co-packaged-optics/
- Publisher: NVIDIA
- Published: 2025-08-26
- Role: CPO架构与单位用量

NVIDIA described the Spectrum-X Ethernet photonics module as integrating 32 photonics engines and its Quantum-X switch design as using optical subassemblies. The external laser source centralizes light generation, and NVIDIA estimated a fourfold reduction in laser count relative to its legacy design. This is an architecture comparison, not a forecast of total laser orders.
