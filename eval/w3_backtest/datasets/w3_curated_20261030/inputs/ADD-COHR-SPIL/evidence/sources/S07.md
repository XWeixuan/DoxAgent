# Spectrum-X Ethernet Photonics enters full production

- 发布者：StorageReview
- URL：https://www.storagereview.com/news/nvidia-spectrum-x-ethernet-photonics-enters-full-production-with-4x-fewer-lasers-and-a-five-vendor-cpo-supply-chain
- 发布时间：2026-08-15
- 角色：同期具体平台供应分工

报道 NVIDIA 已将 Spectrum-X Ethernet Photonics 进入量产；所列该交换机供应链包括 TSMC 硅光子制造、SPIL 芯片级封装测试、Lumentum 激光芯片、TFC 激光模块和 Foxconn 总装。这是针对该平台的具体供应链。
