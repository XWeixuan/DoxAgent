# NVIDIA Announces Spectrum-X Photonics

- 发布者：NVIDIA
- URL：https://nvidianews.nvidia.com/_gallery/download_pdf/67d9bf5b3d6332b0a6d11f0e/
- 发布时间：2025-03-18
- 角色：既有平台及生态

NVIDIA 介绍将硅光子技术集成到 Spectrum-X Ethernet 和 Quantum-X InfiniBand 交换机，列出的生态包括 Coherent、SPIL、TSMC、Lumentum 等；Coherent 等也提供可插拔光收发器。公告把交换机及生态合作分别列示。
