# Inside NVIDIA Rubin GPU architecture

Publisher: NVIDIA
URL: https://developer.nvidia.com/blog/inside-nvidia-rubin-gpu-architecture-powering-the-era-of-agentic-ai/
Published: 2026-07-21
Role: compute memory architecture

NVIDIA describes Rubin as integrating up to 288 GB of HBM4 through 12-Hi stacks, providing up to 22 TB/s peak bandwidth. It says this supports large context and high-concurrency inference. The design specification is a platform description, not proof that any specific user order contains Micron memory.
