# PJM proposes curtailment rules for new large loads

- 发布者：Tom’s Hardware
- URL：https://www.tomshardware.com/tech-industry/data-centers/new-data-centers-on-americas-largest-grid-face-first-in-line-blackouts-unless-they-bring-their-own-power
- 发布时间：2026-08-17T13:11:38Z
- 角色：同期规则背景

PJM 提议针对未自带或落实电力的新接入 50 MW 以上负荷，在供电紧张时优先限电；PJM 表示实际限电依赖电力公司和州政府。该提议与一次性 backstop 采购是不同机制。
