# FERC asks grid operator PJM to revise plan to shield homes from data center costs

- 发布者：Reuters via EnergyNow
- URL：https://energynow.com/2026/09/ferc-asks-grid-operator-pjm-to-revise-plan-to-shield-homes-from-data-center-costs/
- 发布时间：2026-09-30
- 角色：原消息正文

Laila Kearney 报道：FERC 部分接受 PJM 的一次性 backstop 采购计划，同时暂停五个月并对成本分摊等事项继续审议；PJM 原拟周三启动。该计划针对超过 6,800 MW 的供应缺口。FERC 要求改进大型用电者承担成本以及负荷预测；PJM 表示正在落实指令。
