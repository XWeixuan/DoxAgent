## 核算口径

- 时区为 `America/New_York`，以每日 15:30 为持仓周期边界：若入场发生在当日 15:30 前，于当日 15:30 清仓；15:30 后则于下一交易日 15:30 清仓。跳过周末。本样本区间没有需要跨越的美国股市节假日。周期依真实入场时间（已成交）或意图释放时间（未成交）确定。
- 已成交记录用导出的经纪商平均入场成交价；未成交记录用 IBKR TWS `TRADES` 历史逐笔成交，在意图释放后 60 秒内的首个正常报告成交价作为假设入场价；若该范围没有正常报告成交，才采用该范围的首笔其他历史成交，并保留 `unreported` 标记。无滑点、手续费、融资成本和买卖价差。这里只用历史成交作为市价代理，不能保证假设市价单可按该价成交。
- 统一退出价为周期结束 **15:30:00 美东时间**之后 5 秒内的首个正常报告成交价。所有 77 条都取得了 15:30 退出价；实测采用的退出 tick 与边界的间隔至多 1 秒。真实交易的实际退出成交价/已实现净盈亏没有替代此回测退出价，因此本结果不等同于真实交易盈亏。
- LONG 收益率 = `(退出价 − 入场价) / 入场价`；SHORT 收益率 = `(入场价 − 退出价) / 入场价`。严格高于 +2% 为胜，严格低于 -2% 为负，闭区间 [-2%, +2%] 为平。先用未四舍五入的收益率分档，再在逐案文件中显示 4 位小数。
- IBKR 请求均为只读合约解析和历史逐笔成交。合约 ID、连接版本和采集时间见 `connection.json`；请求起点、选中的 tick、其交易所和异常见 `queries.jsonl`。逐案结果在 `results/`，按 ticker 每份最多 5 条，共 16 个 JSON。源样本在 `../w3_trade_intent_review_20261010/export/`。
