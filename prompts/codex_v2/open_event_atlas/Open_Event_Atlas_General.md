# Open Event Atlas — General（最终严格筛选版）

> 用途：仅作为后续研究 Agent 的开放事件灵感启发，不意味着每条都应生成 Policy。
> 最终筛选标准：事件类型须同时具备（1）不算太低的现实发生概率；（2）一般情况下较明确、较容易形成短期价格发现的机制；（3）有不低概率通过公司、新闻媒体、政府/监管/司法/交易所、客户/供应商、研究机构、公开数据或其他第三方可监测渠道形成公开披露或可验证公开信号。
> 一项特别强可以有限补偿另一项，但任一门槛明显偏低都不保留。本稿仍不定义方向、Ticker 适配性或 Policy 触发条件。

## 信息披露、研究观点与认知冲击

- 主要卖方机构显著调整评级、目标价、盈利预测、核心估值论点或重点推荐名单。
- 多家有影响力研究机构在短期内集中修订同一行业的市场规模、增长路径或竞争格局判断。
- 做空机构发布针对公司商业真实性、财务披露或治理问题的实质性调查报告。
- 调查媒体、员工、前员工或业务合作方以可核验证据揭示此前未公开的重大经营或治理事实。
- 广泛传播的重大合作、订单、技术或交易传闻获得独立确认，或被相关当事人正式否认。
- 公司对重大指控作出有证据的实质性反驳，或承认关键事实并重新界定事件性质。
- 管理层在公开交流中显著改变关键业务表述，或对同一重大事项给出相互矛盾的说法。
- 重要客户或合作伙伴在自身披露中首次给出目标公司未公开的合作、采购或项目细节。
- 竞争对手在自身公开交流中披露足以改变市场既有行业判断的重要事实。
- 重大公告提前泄露，正式披露时对泄露版本作出实质补充、修正或否定。
- 独立复核推翻市场广泛采用且直接影响估值或业务判断的关键计算、比较或叙事。
- 原被视为孤立的多起异常事件被新的调查证明具有共同原因。

## 指数、上市制度与交易可达性

- 主要指数发生成分股纳入、剔除、权重调整，或指数资格与计算规则变化直接改变资金配置。
- 股票发生主要交易所升板、退市风险、恢复合规或复牌/重新上市等上市状态变化。
- 监管或市场互联安排改变境外投资者对某类证券的实际交易资格或跨境可达性。
- 主要经纪商、零售平台或清算机构限制、恢复特定证券的开仓、交易或结算能力。
- 公司证券被列入或移出特定投资者依法不得持有的名单。

## 持仓、基金资金流与衍生品

- 高关注机构、大型投资者或重要股东披露新建、清空、显著调整或通过衍生品形成的重要经济敞口。
- 大股东股权质押触发补充担保、强制出售或控制权风险。
- 大型基金清盘、集中赎回或暂停赎回，形成可识别的被迫资产处置压力。
- 重要持有人发生规模显著的大宗减持、协议转让或限售/减持安排变化。
- 大额证券出借被召回，或可借券数量、借券费率与条件发生异常变化。
- 高关注股票出现突发且规模化的散户集中交易或网络协同行动。

## 所有权、治理与关键人员

- 激进投资者、股东联盟或代理投票力量公开挑战公司战略、董事会或资本配置，并实质改变关键表决结果的通过前景。
- 公司采用或调整反收购、双重股权、特别表决权等控制权安排。
- 首席执行官、财务负责人等关键管理层突然离任、提前更替或由明显不同战略背景的新团队接任。
- 关键高管因监管、刑事或利益冲突被停职，或董事因重大分歧辞职并公开说明原因。
- 特别委员会或内部调查发现管理层、交易或授权程序存在重大问题。
- 控股股东与上市公司之间的重大关联交易受到独立性或利益输送质疑。
- 董事会突然撤回或推翻此前批准的重大公司战略。

## 并购、资产重组与控制权交易

- 公司收到重大收购、私有化或合并提议，或公开启动出售、合并及战略替代方案。
- 已宣布重大并购的价格、支付方式、交易范围或融资条件出现实质变化。
- 已宣布并购因违约、重大不利变化或退出争议被终止并触发补偿安排。
- 重大并购的监管、股东或司法批准条件变化，使交易获批、受限、受阻或恢复推进。
- 公司宣布或显著调整分拆上市、业务分离或子公司上市方案，并形成新的独立估值。
- 公司出售或重新取得重要经营资产、知识产权、业务线或地区经营权。
- 重要资产交易价格显著偏离账面价值或市场此前估计。
- 大型业务出售、拆分或独立交易首次为此前混合在集团中的资产提供清晰市场估值。
- 同一行业多家公司连续进入出售、合并或整合程序，形成行业级并购重估。
- 公司正式退出一项重要业务并公布相关资产、合同和客户处置方案。

## 股本、资本回报与融资安排

- 公司公布、显著调整或取消重大股权融资，且发行价格、规模、认购结构或净募集发生实质变化。
- 战略投资者以显著不同于公开市场的条件认购公司股份。
- 公司发行、赎回、交换或重设具有转换、赎回、认股或特殊分配权的重大证券。
- 公司启动、扩大、缩减、暂停或受限制执行重大股票回购。
- 公司宣布特别股息、资本返还，或首次派息、恢复派息及停止既有派息安排。
- 公司与外部资金方签订或调整具有实际经济约束的共同投资、项目融资、预付款或融资承诺。
- 公司通过售后回租或其他方式大规模货币化经营资产。
- 重大融资安排首次披露最低产量、库存上限、保底回报、补足或其他重要经济约束。
- 公司显著改变资本配置优先级，或将大额资金转向非主营资产、储备或新的战略用途。
- 政府、战略基金或产业资本取得公司重要股权并附带经营条件。

## 信用、流动性、保险与金融风险外溢

- 信用评级、债券或信用违约掉期出现显著重定价，揭示与股票市场认知不同的信用风险。
- 公司发生重大契约违约、交叉违约、债务未付、加速到期、豁免或暂缓追索等偿债状态变化。
- 重大再融资失败或新融资条款明显恶化并限制资本开支、分红、收购或资产处置。
- 银行或银团缩减、终止重大授信，或公司异常提取大部分备用授信。
- 重要客户撤回、要求退还或重新附加保障条件于重大预付款。
- 此前未充分披露的反向保理或其他隐性融资规模被揭示。
- 公司进入、退出破产重组，或重组方案实质改变股东与债权人受偿权益。
- 重要客户、供应商或合作伙伴出现足以影响交易履约的信用恶化、违约或资金断裂。

## 会计、审计与披露可信度

- 公司宣布此前财务报告不再可靠并启动重大重述。
- 审计机构出具重大保留/否定/持续经营意见、因分歧辞任，或公司无法按期完成审计和法定报告。
- 审计或公司披露重大内部控制缺陷及其修复失败。
- 收入确认、总额净额口径或交易主体认定受到实质性质疑。
- 公司重要非GAAP/调整后指标被撤回、重释，或原称一次性的项目被重新认定为持续性。
- 公司披露此前未计入的重要担保、采购承诺或其他表外义务。
- 重大关联方交易被发现未充分披露或缺乏独立交易基础。
- 公司承认关键经营指标存在重复计算、定义变化或历史序列被实质追溯修订。
- 公司对商誉、无形资产或其他重大资产确认重要减值或价值重估。

## 诉讼、调查与权利争议

- 核心业务或重大资产相关诉讼被提起、驳回，或集体诉讼资格及适用范围发生实质变化。
- 法院或监管机构针对重大业务发布、扩大、暂停或撤销具有约束力的禁令。
- 司法程序公开此前保密且可能改变案件或经营判断的重要内部证据。
- 法院、陪审团或上诉程序对重大案件作出实质改变责任、赔偿或经营权利的裁决。
- 重大诉讼达成、撤销或重新谈判和解，并改变赔偿或行为义务。
- 企业或关键高管受到刑事起诉，或与执法机关达成显著改变法律风险的认罪、不起诉或延期起诉安排。
- 重大监管调查启动、升级为正式执法行动，或宣布结束且不再采取原预期处罚。
- 核心知识产权或重要许可协议的效力、销售、进口、生产或使用权受到重大司法或合同变化。
- 重要客户或合作伙伴援引不可抗力、情势变化或合同退出条款改变重大项目义务。

## 监管、准入与商业规则

- 关键经营许可、豁免或认证获得、撤销、恢复或延长，并实质改变可开展业务范围。
- 重要监管规则正式发布、延期、撤回或被重新解释，改变企业可执行的商业边界。
- 监管机构改变执法重点，对此前被容忍的重要商业做法集中采取措施。
- 监管机构新增许可要求、重新分类产品/服务或扩大既有限制的产品、地区与客户范围。
- 技术、安全、可靠性或质量标准改变认证条件并迫使既有产品重新符合要求。
- 产品被监管要求召回、停售、停用或强制整改。
- 数据跨境、本地化、隐私或数据使用规则发生重大变化。
- 平台监管要求开放接口、禁止自我优待/排他、限制收费或改变关键网络与市场接入权。
- 外资准入或国家安全审查要求改变持股、控制权或业务隔离安排。
- 原产地、供应链审查、贸易救济、海关归类或进出口规则变化实质改变贸易许可与成本。
- 建设许可、用地审批或地方容量限制被暂停、重启、加速或收紧，改变重大项目可行性。

## 公共政策、政治地缘与政府采购

- 选举、执政联盟或政府更迭实质改变已公开的产业、贸易或监管政策路径。
- 政府或立法机构撤回、重写、通过或否决影响行业的重要产业政策和法案。
- 政府预算谈判、公共预算追加或削减使重要项目资金出现实质变化。
- 政府补助、税收优惠或投资激励的额度、资格、条件及实际拨付安排发生重大变化。
- 政府采购的规模、技术路线、供应商资格或既有合同执行发生重大变化。
- 双边或多边贸易协定签署、暂停或终止并改变市场准入。
- 制裁、对外投资限制、技术转移或出口管制新增、扩大、解除或取得关键豁免。
- 关税谈判形成新协议或既有暂缓安排破裂。
- 地区冲突、封锁或停火发生重大变化并改变关键贸易、运输或能源通道。
- 政府要求迁移生产、数据、研发或供应链，或资本/外汇管制改变利润和资金跨境流动。
- 政府大型基础设施计划启动、削减、取消或改变技术路线。
- 政府对新兴技术采取暂停部署、限制使用或加速推广行动。
- 国家安全事件触发对关键供应商、技术依赖或采购范围的重新审查。
- 官员利益冲突、腐败或采购舞弊调查直接牵涉相关企业或合同。
- 地方公投、社区表决或自治机构决定改变重大项目的许可基础。

## 宏观、跨资产与独立数据

- 央行作出明显超出此前市场预期的利率或资产购买决定。
- 官方宏观经济数据出现显著偏离共识的结构性变化。
- 海关或跨境交易数据揭示此前未被广泛认识的需求、出口或供给迁移。
- 支付、结算或消费数据与公司或行业公开叙事出现显著背离。
- 网络访问、应用使用或用户活跃等高频数据出现足以改变需求判断的规模变化。
- 卫星、地理活动或现场观测显示重大项目进度与公开说法显著不一致。
- 物流、运输或仓储数据揭示此前未被识别的重要积压、中断或库存变化。
- 独立调查发现订单取消、渠道折价或客户预算变化显著超出既有认知。
- 行业统计或多个独立数据集共同修正市场规模、份额或需求持续性判断。
- 关键商品基准价格、期限结构或主要生产者联盟的产量/出口安排发生显著变化。

## 客户、对手方、竞争与跨行业变化

- 重要客户首次公开此前未披露的大额长期采购、使用或容量承诺。
- 大型客户或采购联盟显著改变采购权、供应商评选、独家/多源/第二来源及最低采购安排。
- 重要客户在自建、自营与外部采购之间重新分配重要业务环节。
- 客户因融资、建设、监管或选址问题显著改变已公开的大型部署计划。
- 客户采用新的技术路线或业务标准并重新确定合格供应商范围。
- 大型平台将原由独立企业提供的重要功能直接纳入自身基础服务。
- 重要供应商退出、停止外供或重新分配有限资源的供货优先级。
- 供应商向新竞争者开放关键产能/技术，或关键投入出现新的可商业利用来源。
- 多家企业共同扩建共享瓶颈设施，或跨区域供应安排实质缓解行业级约束。
- 重要竞争者退出、破产、获得救助或战略资本，显著改变竞争供给能力。
- 新进入者或现有竞争者通过新的收费模式、降价、免费或重打包获得规模采用。
- 大型跨界企业进入专业市场，或原本互补的参与者开始直接竞争。
- 纵向整合或去中介化改变上下游利润分配、客户关系和渠道控制权。
- 大型下游项目选择新的技术类别，或新终端需求形成与原主流不同的产品组合。
- 替代方案因监管/质量/供给退出，或邻近行业成本突破重写技术经济性比较。
- 多家公司同时披露相似的订单、交期或配置变化，形成新的行业共同事实。
- 合作伙伴在自身披露中修正目标公司相关重大项目的规模、进度或商业状态。
- 客户群体集中提前囤货、锁定长期供给，或在短缺缓解后集中取消重复订单。

## 技术、标准、平台与商业生态

- 独立测试、复现或真实应用结果显著改变市场对不同技术路线性能、成本或可行性的判断。
- 原本停留在实验室或试验阶段的技术首次形成可重复的商业应用。
- 被广泛采用的技术被发现存在共同的重大性能、安全或可靠性缺陷。
- 重要技术标准被采纳、废弃、分裂或改变开放/专有许可条件，重塑兼容性和生态准入。
- 核心开源项目改变许可证/治理，关键维护团队退出，或行业广泛依赖的软件与工具停止维护。
- 主要平台终止对重要旧产品、接口或技术版本的兼容支持。
- 重要平台显著改变第三方接口、数据调用、开发者准入、计费、分成或直接客户关系。
- 主要生态控制者改变默认设置、推荐位置或预装规则。
- 新技术使某类原本独立收费的重要功能迅速商品化或成为基础能力。
- 技术效率发生实质突破，显著改变完成同类任务所需的算力、能源、材料或其他资源。
- 主要研发主体暂停、恢复或重新限定一项重要技术的开发与部署。
- 新的互操作或迁移工具显著降低原有生态的转换成本。
- 行业联盟建立能够挑战既有主导平台的替代技术生态。
- 技术突破绕开此前不可替代的重要材料、部件或工艺环节。
- 重大技术安全事故促使多家企业暂停同类系统或功能。
- 新用途或真实用户行为使既有技术的商业价值和原设计假设发生实质变化。

## 社会行为、声誉、劳动与组织性行动

- 消费者或相关社群围绕企业品牌、产品或行为形成规模化且持续的抵制或支持运动。
- 社交传播或文化潮流推动产品/服务突然获得规模采用，或快速失去原有热度。
- 创始人或与品牌高度绑定的核心公众人物陷入重大声誉争议并影响企业合作或客户关系。
- 重大声誉事件促使重要客户或合作伙伴暂停合作、重新审查或排除供应商。
- 消费者集中披露严重产品问题或安全担忧，并引发大范围调查、赔偿、召回或官方结论反转。
- 用户、创作者、开发者、商家或专业用户出现规模化迁移或集体退出某一平台生态。
- 社区或地方组织的有组织行动实质阻断重大项目，或通过约束性和解重新开放经营路径。
- 重大劳资冲突升级为罢工、怠工或停工，或通过新的劳动协议解除停工威胁。
- 强迫劳动、严重劳工或安全问题被揭露并触发重要客户、海关或认证机构行动。
- 政府、社区或消费者推动并实际形成对某类商品或服务的使用限制或禁令。

## 灾害、公共事件、基础设施与网络安全

- 重大自然灾害导致重要企业设施或产业集群停摆，并出现超出初始预期的实际损害。
- 长期干旱、缺水或关键资源限制迫使企业实质调整运营。
- 重要经营设施发生严重工业事故、安全停运或复工争议，事故调查改变实际影响范围。
- 关键公共电力、供水、通信或燃料系统故障或限供，迫使企业停产、降载或调整调度。
- 大型共享基础设施项目显著延期、提前建成或扩容，改变相关企业的接入能力。
- 关键贸易或物流通道因关闭、改道、罢工或边境拥堵发生实质中断。
- 企业遭受重大网络攻击、长期入侵或数据泄露，并影响核心系统、客户数据或客户继续合作。
- 关键第三方软件、云服务、身份认证或外包平台发生大范围故障并中断企业服务。
- 行业共同使用的软件组件被发现存在严重漏洞，迫使大范围修复或暂停。
- 企业失去关键云、软件、支付或数字经营入口的访问权，导致业务无法正常提供。
- 突发事件暴露多家企业共同依赖的关键基础设施、软件或供应商存在系统性风险。
