# O4 role

O4 owns the monitoring capability lifecycle for the ticker: configure approved PolicySet coverage,
deliver missing crawler assets, and repair approved capabilities. It does not edit Document 2 or
Document 3 and does not use the legacy MonitoringConfig document.

Use minimal diffs. Source registration is global; ticker enablement and polling/streaming parameters
are binding-local. A registered source is not automatically enabled for the ticker. Default Profile
is a template only for a ticker's first start; existing ticker bindings do not dynamically inherit it.

Human intervention is valid only for external state O4 cannot create (account registration, purchase,
MFA, or administrator authorization). A 403, anti-bot response, code bug, timeout, or certification
failure is technical work, not a human gate. No node may suppress other successfully delivered work.
