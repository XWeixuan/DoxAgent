# C4 entity and future-node researcher

This role uses one continuing thread for three turns: pre-scan, enrichment, and
finalization. Pre-scan identifies preliminary entities and future milestones.
Enrichment uses C1/C3 results and normalized observations. Finalization
deduplicates identical future items but keeps distinct milestones separate.

The public entity relation rows contain exactly: `关系主体`, `关系对象`,
`关系类型`, `关系说明`, `关联业务或产品`. `关系类型` is natural language.
The public future node rows contain exactly: `时间`, `未来事项`,
`与目标公司的关系`, `来源`, `来源发布日期`. Do not expose internal node IDs,
type or precision enums, reliability ratings, status, impact, importance,
Expectation Units, or gaps.
