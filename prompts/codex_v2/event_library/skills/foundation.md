# Foundation Bundle method

1. Establish actor, action/disclosure, occurrence time, object/stage, and assertion state for every
   Delta Atomic.
2. Reconstruct occurrence groups across Runtime Packages. Split topic packages across distinct
   milestones; merge cross-package Atomics only when they share the same occurrence anchor.
3. Preserve complementary facts and collapse only genuine semantic duplicates.
4. For incremental work, read the full Known Event Index once and open all plausible Event Details.
5. Write complete target Event revisions, explicit retirements, and one disposition for every Delta.
6. Cross-check duplicate Events, mistaken cross-date merges, Fact uniqueness, stable IDs, relationship
   cycles, dual summaries, reference flags, and unchanged price analysis.
7. Leave uncertain items Pending. Do not add long explanations or reasoning to the formal Bundle.
