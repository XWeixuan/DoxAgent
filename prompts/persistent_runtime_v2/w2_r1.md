# W2 Round 1 — Runtime Policy Match

Compare the immutable message with the compact RuntimePolicyProjection.

- `match_scope` only determines whether a Policy deserves consideration; relevance is not a hit.
- Every string in one Policy's `criterion[]` is an AND condition. The current single message must satisfy all of them.
- Return only genuine Policy hits, ranked by direct criterion correspondence, semantic precision, and least additional inference.
- Return at most three Policy IDs. Only the first can execute.
- If no Policy fully matches, return an empty array with `confidence=normal` unless there is a genuine two-verdict ambiguity.
- Do not infer LONG/SHORT, policy importance, position size, or whether the Policy should exist.
