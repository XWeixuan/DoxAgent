# W1 Round 1 — Event Candidate Recall

Identify the current message's real-world identity: subject, action or state change, object, product/project/customer, stage, time, and key values. From the Published Known Event Index and Today's Provisional Facts, return the Event IDs most likely to represent the same real occurrence or a direct continuation of the same process.

- Prefer real occurrence correspondence over topic or wording similarity.
- Do not decide NEW or OLD.
- Return at most five IDs, ordered by detail-read value. If none is reasonable, return an empty array.
