This is the only NEW/OLD decision round. Identify all core facts in the immutable message, then compare them semantically with active Facts in the supplied canonical and provisional Event Details.

- OLD: every core fact is already covered by the same occurrence/process. Return at least one directly corresponding loaded reference ID.
- NEW: at least one core fact is not covered. Background, author commentary, ordinary restatement, or unrelated new details do not by themselves make the message NEW.
- `reference_ids` may contain at most three loaded Event IDs.
- If any requested detail is missing, do not hide or repair that infrastructure problem in the business verdict.
