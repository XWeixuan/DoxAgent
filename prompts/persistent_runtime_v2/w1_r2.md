# W1 Round 2 — Fact Coverage / Novelty

你正在执行 W1 的最终事实新旧判定。

上一轮已经从紧凑索引中选出了可能相关的 Event。本轮提供这些 Event 的完整 Detail，包括 Canonical Event 的 active Facts，以及当前允许读取的 provisional facts。这些事实已在当前消息之前由其他消息形成，不是对当前消息的抽取；其中可能包含尚未被 Active Bundle 吸收的跨日事实。其 semantic_day 只表示原始记账归属，不会因为跨日而失去事实覆盖效力。

你的任务不是决定 Event Library 最终应该新建 Event、更新旧 Event 还是合并 Event。那属于后续 Event Library 的工作。

你只回答一个问题：

> 当前消息的核心事实，是否已经被当前已知现实覆盖？

W1 的价值是保持现实记忆准确而连续：既不把已经知道的事实重复识别为新信息，也不把真实发生的状态变化误认为旧消息。

## 核心概念

### Event 与 Fact

Event 表示一次有现实身份的 occurrence 或持续发展的现实过程。

Fact 是关于现实的一个具体事实命题。

同一个 Event 可以不断产生新的 Facts。因此：

> 当前消息属于一个已经存在的 Event，并不意味着它一定是 OLD。

例如，同一客户资格过程可以先后出现：

- 开始测试；
- 进入 qualification；
- qualification 完成；
- 开始商业出货。

这些可以属于同一现实过程，但后续阶段仍然是新的事实。

### 核心事实

“核心事实”是构成当前消息主要新闻进展的具体现实陈述；如果去掉它，会改变这条消息实际上在报道什么。

核心事实通常涉及：

- 谁做了什么；
- 某状态或阶段发生变化；
- 某产品、项目、协议或客户关系取得新进展；
- 某个重要数值出现新的实际变化；
- 某计划被正式确认、推迟、取消或否认。

历史背景、重复介绍、无关旁支信息、作者评论以及不改变主要新闻进展的附带信息，不因为本身此前没有出现过就自动构成 NEW。

### Fact Coverage

“已覆盖”是语义上的事实覆盖，不要求文字相同。

如果现有 Fact 已经表达了当前核心事实的同一现实命题，就属于已覆盖。

例如：

- Known：客户已经完成 qualification
- Message：客户正式通过 qualification

核心事实已经覆盖。

但状态、阶段、数量或事实性质发生变化时，不属于覆盖。例如：

- Known：qualification testing 正在进行
- Message：qualification 已完成

这是新的核心事实。

同样，传闻、计划、预测与已经发生或正式确认的事实不能因为主题相同而简单视为同一个事实状态。

## 判断顺序

先独立理解当前消息，再使用 Event Detail 进行比较：

1. 识别当前消息真正的核心事实。
2. 判断加载的 Event 与消息属于同一 occurrence、同一现实过程，还是不同 occurrence。
3. 将每个核心事实与已加载的 Canonical Facts 和 provisional facts 比较。
4. 区分事实覆盖与单纯的措辞变化、重复报道、背景引用或评论。
5. 判断是否存在尚未被覆盖的核心事实。

最终规则：

- 当前消息的 **全部核心事实都已经被覆盖** → `OLD`
- 当前消息存在 **至少一个尚未被覆盖的核心事实** → `NEW`

不要因为消息含有不相关的新细节，就把一个核心内容完全重复的消息判为 NEW；判断对象始终是消息的核心现实进展。

如果上一轮没有找到候选 Event，仍应根据当前消息和本轮实际提供的已知事实完成判断，不要因为没有候选而机械推断其他信息。

## reference_ids

如果结果为 `OLD`，返回最直接证明当前核心事实已经被覆盖的 Event ID；只选择真正支撑 OLD 判断的 reference，不需要列出所有相关 Event。

如果结果为 `NEW`，通常可以保持为空。只有当某个已加载 Event 明确代表当前消息的既有状态，而当前消息是在其基础上产生了新的核心进展时，才返回这个 Event 作为有意义的历史参照。

## confidence

先完成 NEW / OLD 判断，再判断 confidence。

`normal` 是默认值。普通的不完整信息、不是百分之百确定、没有更多资料可看，都不是使用 `low` 的理由。

只有同时满足以下情况才使用 `low`：

1. 存在一个会改变 NEW / OLD 结果的关键歧义；
2. NEW 和 OLD 两种相反解释都能够从当前消息和已加载事实中得到具体、合理的支持，而不是仅由信息缺失或额外假设产生；
3. 根据当前上下文无法消除这个歧义。

当三个条件确实同时成立时，应使用 `low`，不要仅因为其中一个解释看起来更自然或更常见就忽略另一个同样有事实支持的解释。

如果使用 `low`，`reason` 必须明确指出这个会导致两个不同 verdict 的具体歧义；如果无法指出这样的歧义，应使用 `normal`。

## reason

只记录决定结论的事实差异，不展开完整推理过程。

- `OLD`：简要指出哪个核心事实已经被已知 Fact 覆盖。
- `NEW`：简要指出哪个核心事实是现有 Detail 尚未覆盖的新进展。
- `low`：简要指出导致 NEW / OLD 两种结果均有可能成立的关键歧义。
