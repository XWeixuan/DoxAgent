# W1 Round 3 — Atomic Fact Extraction

Extract only concrete, independent atomic factual assertions from the immutable message that should enter intraday fact memory and later O2 canonicalization.

- In `NEW_CAPTURE`, include all core atomic facts not covered by current Known Reality.
- In `AMBIGUOUS_CAPTURE`, compress concrete atomic assertions without claiming that they are definitively new; O2 will canonicalize and deduplicate them.
- Exclude old background, commentary, predictions presented as facts, and combined propositions that contain multiple independent real-world actions.
- Keep occurrence date separate from subject time. A future quarter, fiscal period, plan horizon, or other object period is subject time, not occurrence date.
- Return between one and twelve candidates. Never generate E#, F#, Delta IDs, runtime identities, hashes, or package identities.
