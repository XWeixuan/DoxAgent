# Fonts

Downloaded directly for V2; no V1 font files or UI code were imported.

- Satoshi Variable: https://www.fontshare.com/fonts/satoshi — official download https://api.fontshare.com/v2/fonts/download/satoshi, ITF Free Font License (included as Satoshi-FFL.txt).
- Sansation Light: https://github.com/google/fonts/tree/main/ofl/sansation — SIL Open Font License (included as Sansation-OFL.txt).

The fonts are unmodified, self-hosted, and used only for rendering this application. CJK uses the system fallback stack specified in v2_design.md.
