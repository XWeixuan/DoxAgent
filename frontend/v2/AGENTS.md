# V2 前端开发约束

以下为用户于 2026-09-08 明确确认的长期要求，适用于所有后续页面与迭代：

- 这是用户自用、熟悉业务的数据看板。以两份 V2 PRD 为功能与信息依据；未要求且无实质用途的说明、装饰、宣传、引导文案或组件一律不加。不得添加常驻环境标签、版本徽标、装饰英文眉题、口号、页脚、重复指标说明。错误、未知值、权限限制、必要字段名和影响操作的反馈应保留。
- 以合理且均匀的信息密度组织页面：状态与指标紧凑并列，缩小标题及模块间距，不用低密度大卡片或宽间隔填充空间。可用有意义的图标、语义色与结构区分信息；不得用额外文案填充。
- 高频内容优先可读：普通标签、表格正文以 14px 为基准，控件与主要阅读内容 14–16px，小型状态标签可为 13px。不得用缩小字体解决布局问题；按宽度调整结构。
- 先从 PRD 理解页面业务和高频路径。Overview 标的行的非控件区域整体可导航；保留原生链接以支持键盘操作，行内控制操作不得触发导航。初始化中的标的仍遵守 PRD 的访问限制。
- 表头与对应内容使用一致的列边界、对齐规则与内边距；数值右对齐、文字左对齐、操作区居中。本次仅交付桌面端；浏览器至少检查 1262px 和 1559px 两种桌面宽度，验证无重叠、无页面横向溢出及无控制误触，不开展手机适配。
- 环比变化用颜色和箭头共同表达方向。方向不等于好坏，不把成本上升等自动解释为成功；使用独立的升降色令牌。

## 页面重做与验收补充（2026-09-08）

- 简洁不代表省略组件设计。用清晰的内容层次、对齐、选中态、图标、分隔与语义色改善阅读和操作，不能用一组无差别边框交差。
- 逐页完成实现、浏览器检查和交互验证后再进入下一页。必须进入可访问的 V1 真实网页观察排版、组件与交互，记录具体可取和不足之处；V1 只是对照基准，不代表达标，不复制其实现或过时业务语义。
- 全局只保留 Logo 返回 Overview；Logo 在左，标的切换器在其右侧。标的导航居中，选项有图标与分隔线，依次为基础投研、预期研究、交易策略、事件库、消息总线、运行状态、收益 / 成本审计。
- Shell 等内容选择器服从信息层级，策略页放在 KPI 下方。事件索引使用右侧收起的阅读位置索引，悬停或键盘聚焦展开，定位原列表项目，不另造独立结果页。
- 消息流必须放在有界、独立滚动的组件内；控件分工明确，页面模式、统计周期与内容筛选不可层层堆叠。正文按需展开，加载更多不能扩张整页高度。
- Runtime 连线不得穿过未经过的节点；边计数有独立底色且不能重叠节点文字。节点必须可选、显示对应统计与 Case 列表，并可继续打开判断与逐次尝试明细。
- 交付记录必须区分浏览器实际验证、静态检查与尚无数据的分支；不得把构建通过或少量 mock 正常态直接写成完整业务验收。

视觉依据：[v2_design.md](../../dev_plan/v2_design.md)。保持 V2 Greenfield 隔离，不引入 V1 页面、组件、样式或 DTO。

## 最新浏览器批注修订（2026-09-08）

- D1/D2 历史用左侧概况卡片，选择后切换主阅读区，不激活旧文档。D2 层级为 Shell → Unit → State/Factors/Gaps → 具体条目，主阅读区只显示当前 Unit；数值字体与正文一致。
- 策略变更时间线位于全局操作区，读取当前 ticker 全 Shell、全历史的正式定义变更；卡片内删除版本/消费/生效行。Shell 横向滚动并有边缘渐隐，与状态下拉同排分隔，索引复用事件右侧隐藏形式。
- 事件周期放在刷新左侧，模式与状态筛选同排分隔。删除事件元数据行，is_important 移到标题右侧；当前契约该字段只在 EventDetail，不能假定未加载详情的事件不重要或批量预取全部详情。
- 消息周期只影响 KPI；列表按完整保留窗口独立筛选。收起显示正式正文预览，按进入可视区的卡片读取首块，展开沿用同一 body，不生成摘要。轮询环依据调度事实推进，过期等待重新校准，不用循环动画伪造完成。
- 配置页展示渠道选择、真实运行概况、启用/间隔、运行时段与参数；表单和 JSON 共用草稿，保留 CAS、幂等及参数校验。Runtime 节点详情与图并排，记录表带表头，突出一个或多个最终结果。

- 2026-09-08 细节收尾：D2 索引删除全部类入口并保持 sticky；策略状态下拉固定在 Shell 滚动条左侧；Delta 不展示重复说明。消息收起正文最多五行、流框维持有界高窗口，底部渐隐配居中续页；来源类型位于名称下方、堆叠卡片独立边界。Runtime 状态独立成列，紧跟最终结果。

- 2026-09-09 用户需求修正：策略默认第一个 Shell，正文连续显示当前 Shell 与状态筛选交集的 Policy；右侧索引仅滚动定位，不能切换为单篇。报告选择后自动顺序加载完整正文，D1 未来节点与 D2 当前 Shell 单元自动续取；策略、事件和运行记录使用消息流同款居中箭头续页。D2 实现因素单列、中文章节标题并强化字段标签；消息独立卡片，整卡非控件区域可展开，保留链接、键盘与文字选择。
