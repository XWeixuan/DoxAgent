## 数据与验证边界

- 本地 mock 单价已改为 PRD 固定 qwen3.8-flash 快照：人民币每百万 Token 0.8 / 0.1 / 2.7，按 6.8 换算美元。Input 包含缓存输入，缓存部分不重复按非缓存单价计费；Codex 不计美元。
- 修正后前一交易日 API 总成本显示 $0.027，Overview 两位小数显示 $0.03。共享用量账本，未修改真实数据或交易服务。
- 当前 mock 没有可启动的 control worker，启动与控制按钮保留服务端能力限制；明确显示“启动服务未就绪”。没有为展示而伪造生产可用状态。
- 20 个 Vitest 测试通过；ESLint、类型与生产构建通过。构建仍提示一个既有主入口分块超过 500 kB，这不是运行失败，但后续可单独优化包体。
- 构建通过不能代替业务验收。本轮未证明真实投影/SSE 持续运行、真实启动或交易成交；mock 没有覆盖所有异常、长历史和成交分支。
- 最后的“未来节点”点击发生浏览器控制 CDP 超时，随后只读检查确认仍停在基本面页，因此没有把这次切换写成通过，没有重复点击。该分支保留原实现与类型检查结果。

本次记录描述实际检查证据，不将 V1 对照、正常 mock 页面或自动测试称为全业务验收。后续执行约束已写入 AGENTS.md 与 v2_design.md。
