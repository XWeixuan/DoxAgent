# C3 行业与产业链研究重构架构

## 一、C3 的最终定位

C3 是预期研究之前的行业与产业链研究节点。

它不负责完成正式的外部预期研究，而是：

> **围绕目标公司的主要业务暴露，研究与其经营兑现相关的行业和产业链事实、关键外部主体信号、核心外部驱动、利益与订单分配机制，以及行业里程碑的证明边界，为下游构造外部 Expectation State、Realization Factor 和 Potential Gap 提供研究洞见。**

C3 不再承担传统行业覆盖报告的任务，包括：

* 完整介绍行业历史、规模和发展前景；
* 按公司逐一介绍行业参与者；
* 横向比较谁的竞争优势更强；
* 汇总同业估值；
* 分别形成多家公司的投资逻辑；
* 推荐行业内更值得买入的股票；
* 根据行业信息直接判断目标股票是否已经被市场定价。

当前真实 C3 输出以“行业概览—竞争格局—同业估值—各公司投资思路—风险催化”为主线，分别分析 TSMC、Micron、SK Hynix、Intel 等公司的定位和投资逻辑。这种结构适合传统行业选股，但难以向下游提供可组织为 State、Factor 和 Gap 的研究材料。

C3 也不直接负责：

```text
Expectation Shell
Expectation Unit
正式 Expectation State 组合
正式 RealizationFactor
正式 PotentialGap
Gap Activation
Market Absorption
priced-in 判断
目标价与交易建议
```

Document2 已经规定，C3 主要贡献产业链、竞争、供需、份额和客户侧材料，并提出兑现条件、阻断点和可能的预期修正方向；正式对象仍由 O1 统合。

因此，C3 的最终核心产物是：

```text
目标相关的行业与产业链事实基准
+
关键外部主体的判断与行为信号
+
核心外部驱动、分配机制与传导关系
+
行业与商业化里程碑的证明边界
+
潜在行业与产业链因素缺口候选
+
Unknowns、证据边界与跨节点交接
```

# 三、C3 的核心概念边界

为了避免报告内部重复，C3 必须区分以下六类研究对象。

| 概念                   | 定义                              | C3 中的作用                 |
| -------------------- | ------------------------------- | ----------------------- |
| State                | 当前能够确认和持续维护的数值、区间、时间、阶段、方向或证据状态 | 作为行业与产业链事实基准            |
| Signal               | 某个外部主体的表述、行为或事件所提供的新信息          | 揭示或验证行业变化               |
| Driver               | 导致需求、供给、价格、份额或商业化状态变化的外部变量      | 解释行业变化由什么驱动             |
| Allocation Mechanism | 行业增量或减量如何分配到不同产品、供应商、客户和目标公司    | 判断行业变化是否真正落到目标公司        |
| Transmission         | 外部变量如何经产业链机制影响目标公司的业务状态         | 为 C1 和 Document2 提供传导接口 |
| Milestone            | 产品、客户、供应和商业化过程中可观察的阶段性进展        | 限定事件能够证明什么和不能证明什么       |
| Candidate Gap        | 可能导致未来外部判断发生修正的问题或路径            | 作为下游正式 Gap 构造材料         |

这些对象之间的关系是：

```text
基础 State
+
外部主体 Signal
        ↓
识别 Driver
        ↓
研究 Allocation Mechanism
        ↓
形成到目标公司业务状态的 Transmission
        ↓
结合 Milestone 与证明边界
        ↓
提出 Candidate Gap
```

C3 不将这套关系物化为新的 Registry 或正式下游对象。

# 四、C3 与基础预期指标采集的关系

基础预期指标采集已经负责维护：

* 行业需求；
* 行业供给与产能；
* 价格与单位经济；
* 库存与订单；
* 市场份额与竞争位置；
* 产品和商业化阶段；
* 客户、供应商、竞争者和渠道预期。

这些状态使用统一的 `metric_id`、`StateParameter` 和 `StateValue`，并按照 `ACTUAL`、`SELL_SIDE`、`INDUSTRY_CHAIN` 等来源角色写入。

因此，C3 不得：

```text
重新建立 Industry State Book
重新维护一套行业 Parameter Registry
逐项抄写所有 ind_* 指标
给已有指标建立自然语言别名状态
把基础指标结果重新包装成完整行业数据表
```

二者的分工是：

```text
基础预期指标采集
回答：
当前可以确认和维护哪些行业与产业链状态？

C3 行业与产业链研究
回答：
这些状态为什么变化？
哪些外部主体的信号支持或反对这种变化？
真正重要的驱动和分配机制是什么？
这些变化怎样传导到目标公司的业务状态？
```

C3 可以：

* 读取并引用已有 `metric_id`；
* 选择其中与本次研究主线有关的状态；
* 解释不同状态之间的关系；
* 发现现有指标无法覆盖但值得下游研究的问题；
* 提出具有长期复用价值的新指标候选。

C3 不自行创建新的持久化状态体系。

# 五、C3 与标的关系及经济暴露研究的关系

外部 Codex SDK 研究板块负责建立相对完整的：

* 客户关系；
* 供应商关系；
* 竞争者关系；
* 产品及业务暴露；
* 上下游产业链位置；
* 相关催化剂与可观察节点。

它回答：

> 哪些实体、业务关系和外部变量可能与目标公司相关？

C3 回答：

> 在当前业务周期内，哪些关系和外部变量真正重要，它们正在发生什么变化，又通过什么机制影响目标公司？

关系地图只是候选研究空间，不能直接成为 C3 的研究清单。

正确执行顺序是：

```text
读取目标公司的业务暴露
        ↓
确定本轮最重要的外部经营问题
        ↓
选择少数行业与产业链研究主线
        ↓
围绕主线选择最有信息价值的主体
        ↓
研究其事实、判断与实际行为
```

不得执行：

```text
读取全部客户、供应商和竞争者
        ↓
逐家公司搜索和介绍
        ↓
最后再尝试总结行业结论
```

# 六、研究范围收束机制

C3 的研究视野天然较宽，因此必须在执行阶段完成范围收束。

范围筛选属于 Agent 内部研究规划，不单独成为报告章节，也不创建持久化对象。

## 1. 先选择研究主线，而不是先选择公司

每次研究原则上只保留约 3—6 条核心外部主线，例如：

```text
下游客户资本开支与采购需求
行业供给、扩产与产能释放
价格、库存与订单周期
客户验证与订单分配
竞争者产品和量产进度
替代技术与潜在需求破坏
```

## 2. 外部主线的纳入条件

一条主线应满足以下若干条件：

* 对目标公司的需求、订单、价格、份额、产能、成本或产品进度影响较大；
* 与目标公司主要业务暴露之间存在清晰连接；
* 当前正在发生边际变化；
* 不同外部主体之间存在明显分歧；
* 未来有可能被事件继续验证；
* 与当前主要业务周期相关；
* 能够帮助下游构造 Unit、State 或 Realization Model。

## 3. 外部主体的选择条件

客户、供应商和竞争者只有在能够发挥以下一种或多种作用时才进入主要研究：

```text
观察行业共同状态
揭示需求变化
改变行业供给
影响订单或份额分配
提供领先于目标公司披露的信号
暴露关键产业链瓶颈
形成技术或产品替代
验证或反证目标公司的行业判断
```

某主体即使规模很大，若与当前核心外部问题没有直接关系，也不进入正式报告。

## 4. 内部优先级判断

Agent 可以使用以下思维框架进行收束，但不得输出机械评分：

```text
目标公司经济重要性
×
因果接近度
×
当前边际变化
×
不确定性
×
可观察性
×
时间相关性
```

# 七、C3 最终报告结构

C3 不设置开头摘要，不设置行业投资结论。

最终固定为六个部分：

```text
1. 目标相关的行业与产业链事实基准
2. 关键外部主体的判断与行为信号
3. 核心外部驱动、分配机制与传导关系
4. 行业与商业化里程碑及证明边界
5. 潜在行业与产业链因素缺口候选
6. Unknowns、证据边界与跨节点交接
```

其逻辑顺序是：

```text
外部现实处于什么位置
        ↓
重要外部主体说了什么、做了什么
        ↓
这些信号是否相互支持或矛盾
        ↓
真正重要的外部驱动是什么
        ↓
行业变化如何分配到目标公司
        ↓
哪些里程碑能够确认或否定当前判断
        ↓
哪些外部假设最容易发生修正
        ↓
还有哪些问题无法确认
```

# 八、第一部分：目标相关的行业与产业链事实基准

## 1. 目标

这一部分回答：

> 在当前研究时点，与目标公司主要业务暴露直接相关的行业和产业链状态处于什么位置，近期发生了哪些实质变化？

它是对基础预期指标采集结果的研究性选择和解释，不是重新建设行业状态库。

## 2. 内容范围

根据当前标的和行业适用性，从以下领域选择真正重要的状态。

### 需求

* 终端需求；
* 客户资本开支；
* 采购、订单和使用量；
* 区域及细分需求；
* 客户库存和采购节奏。

### 供给

* 行业产能；
* 新增或退出产能；
* 利用率；
* 良率；
* 投产和量产爬坡；
* 材料、设备、电力和其他瓶颈。

### 价格、库存与订单

* 现货价格；
* 合同价格；
* 折扣；
* 行业及渠道库存；
* 客户库存；
* 订单覆盖；
* 取消率；
* 长协和现货关系。

### 竞争性分配及商业化

* 市场份额；
* 客户验证；
* 供应商资格；
* 订单分配；
* 双供或多供策略；
* 量产及商业化阶段。

## 3. 纳入原则

只保留：

* 对目标公司主要业务有实质影响；
* 相比上一研究周期发生变化；
* 对后续驱动和传导分析必要；
* 能够被可靠证据支持；

的状态。

稳定且没有研究意义的行业背景不进入。

## 4. 输出形式

建议使用“关键事实基准表”：

| 外部主题 | 当前状态 | 相比前期的变化 | 主要比较锚点 | 涉及的目标业务暴露 | 证据引用 |
| ---- | ---- | ------- | ------ | --------- | ---- |

其中：

* 当前状态可以直接引用基础 `StateValue`；
* 不要求重复列出所有指标；
* “涉及的目标业务暴露”只说明关联接口；
* 不在本部分展开完整传导；
* 不判断是否已经被市场定价。

# 九、第二部分：关键外部主体的判断与行为信号

## 1. 定位

这一部分是 C3 独有的重要产物，不能被简单并入“核心驱动”。

它回答：

> 与目标公司最相关的客户、供应商、竞争者和其他产业链主体，最近表达了什么判断，采取了什么实际行动，这些信号之间是否相互验证或矛盾？

外部主体的表述与行为是下游形成外部预期的重要原材料，但 C3 不将其直接组织成正式 Expectation State 或 Expectation Unit。

## 2. 信号类型

### 明确判断

主体直接表达的前瞻性判断，例如：

* 客户预计资本开支继续增长；
* 供应商预计紧缺持续至某个时间；
* 竞争者预计价格继续上涨；
* 行业分析师预计供需在某季度恢复平衡。

### 实际行为

主体已经实施或明确承诺的行为，例如：

* 增加资本开支；
* 建设或取消产能；
* 签署长期采购合同；
* 提前锁定供应；
* 增减库存；
* 涨价或降价；
* 增加第二供应商；
* 调整产品路线图。

### 外部数据变化

例如：

* 客户订单增长；
* 设备商订单变化；
* 渠道库存变化；
* 竞争者利用率变化；
* 供应周期变化。

### C3 研究推断

由多个事实和信号共同支持的解释。

研究推断必须明确标识，不得与外部主体直接披露混合。

## 3. 判断与行为必须分开

主体“说了什么”和“做了什么”不能被视为同一种证据。

例如：

```text
客户表示 AI 需求强劲
```

只能说明其口头判断。

而：

```text
客户提高 AI Capex
签署长期采购协议
提前锁定 HBM 供应
```

则同时提供了：

* 对未来需求的预期信号；
* 对行业订单和供需状态的实际影响。

行为证据通常更强，但也不能机械外推。例如提高 Capex 不一定全部流向目标产品。

## 4. 主体行为的双重解释

每项重大行为都必须分别分析：

```text
A. 它透露了主体对未来的什么判断？
B. 它实际会怎样改变行业和产业链状态？
```

例如竞争者扩产：

```text
预期信号：
竞争者可能观察到较强需求或客户订单

实际行业影响：
未来产能增加，可能缓解短缺并压低价格
```

两种影响可能方向相反，并处于不同时间范围。

因此，需要区分：

* 行为反映的预期；
* 行为造成的实际影响；
* 近期意义；
* 中长期意义；
* 行为是否为不可逆承诺；
* 执行、审批、资金、设备和良率约束；
* 新增产能是否与目标产品真正可替代。

## 5. 横向竞争研究的新用途

竞争者不再被完整介绍，而只作为：

```text
行业状态观察窗口
需求或供给信号源
行业供给改变者
订单和份额分配者
产品与技术替代者
目标公司外部验证或反证来源
```

C3 不回答“竞争者比目标公司更强还是更弱”，而回答：

> 竞争者的最新行动修改了哪个行业变量，对目标公司的外部经营条件意味着什么？

## 6. 信号交叉验证

对于同一外部主题，C3 应检查：

* 客户与供应商信号是否一致；
* 口头判断与实际行为是否一致；
* 竞争者行为是否支持公开行业数据；
* 多个来源是否真正独立；
* 某个信号是行业共同变化还是单一主体特例；
* 信号之间的时间范围是否一致。

## 7. 输出形式

建议采用“关键外部主体信号表”：

| 外部主题 | 主体及角色 | 信号类型 | 判断、行为或数据变化 | 相比此前的变化 | 行业共同信号或主体特例 | 与其他证据的关系 | 证据引用 |
| ---- | ----- | ---- | ---------- | ------- | ----------- | -------- | ---- |

“与其他证据的关系”可以表达：

```text
相互支持
部分支持
存在冲突
无法比较
单一来源
```

这些是报告级分析标签，不进入正式 State Schema。

# 十、第三部分：核心外部驱动、分配机制与传导关系

## 1. 定位

这一部分将原讨论版中的“核心外部驱动”和“外部变量传导链”合并。

原因是 C3 的核心研究价值不只是识别一个驱动，而是同时回答：

```text
什么外部变量发生了变化
→ 它如何改变行业状态
→ 行业增量或减量如何被分配
→ 最终影响目标公司的什么业务状态
```

## 2. 核心外部驱动类型

### 需求驱动

* 客户资本开支；
* 终端产品出货；
* 单位产品内容量；
* 客户库存周期；
* 客户采购节奏；
* 新应用或新市场需求。

### 供给驱动

* 行业扩产；
* 产能退出；
* 良率变化；
* 产能转移；
* 材料、设备或电力瓶颈；
* 投产和爬坡时间。

### 价格与利润池驱动

* 合同和现货价格；
* 折扣；
* 成本曲线；
* 长协机制；
* 价格弹性；
* 需求破坏；
* 产业链利润在不同环节间的转移。

### 竞争性分配驱动

* 客户供应商资格；
* 订单份额；
* 双供或多供策略；
* 性能、成本和交付能力；
* 客户议价权；
* 竞争者锁定产能或订单。

### 技术与替代驱动

* 客户平台路线图；
* 产品代际变化；
* 竞争技术；
* 客户自研；
* 产品验证；
* 替代方案；
* 技术瓶颈。

## 3. 核心驱动的纳入条件

一个外部因素只有满足以下若干条件，才进入核心研究：

* 能够解释近期重要行业状态变化；
* 对目标公司主要业务状态影响较大；
* 当前存在明显边际变化；
* 有多个相关外部主体持续关注；
* 不同主体之间存在判断分歧；
* 未来可以通过事件继续观察；
* 对其持续性、时间或受益分配存在重大不确定性。

普通行业常识不进入。

## 4. 分配机制是 C3 的核心

C3 不得将：

```text
行业需求增长
```

直接等同于：

```text
目标公司受益
```

必须继续研究行业变化如何分配，包括：

* 新增需求流向哪些产品；
* 客户把订单分给哪些供应商；
* 目标公司是否具备供应资格；
* 目标公司是否有足够产能；
* 竞争者是否提前锁定主要订单；
* 目标公司产品是否达到性能和成本要求；
* 客户是否采取双供策略；
* 目标公司获得的是高价值还是低价值环节；
* 行业增长是否被价格下降、份额流失或成本上升抵消。

分配机制可以表现为：

```text
需求分配
订单分配
份额分配
产能分配
产品组合分配
利润池分配
供应风险分配
```

## 5. C3 的传导边界

C3 的传导终点应停在目标公司的业务状态：

```text
外部变量
→ 行业及产业链机制
→ 分配机制
→ 目标公司业务状态
```

目标公司业务状态包括：

* 订单；
* Backlog；
* ASP；
* 出货量；
* 市场份额；
* 客户数量；
* 客户认证；
* 供应商资格；
* 产能利用率；
* 产品组合；
* 库存；
* 交付周期；
* 商业化阶段；
* 供应链成本；
* 其他公司经营 KPI。

C1 接续：

```text
目标公司业务状态
→ 收入
→ 利润率
→ EPS
→ 资本开支
→ 现金流
```

C3 不负责完整估算收入、EPS 或估值变化。

## 6. 时间维度

同一外部行为可能具有不同时间方向。

例如竞争者扩产：

```text
近期：
扩产承诺可能验证需求和订单可见度

中长期：
产能实际释放可能增加供给并压低价格
```

因此每个核心驱动都必须区分：

* 当前或近期信号；
* 中期实际影响；
* 长期结构影响；
* 行为宣布、建设、投产和有效产能形成之间的时间差。

## 7. 输出形式

每个核心外部驱动使用一行或一组关联行表达：

| 外部驱动 | 当前状态与边际变化 | 主要主体信号 | 行业机制 | 分配机制 | 目标公司业务接口 | 方向 | 时间范围 | 成立条件 | 阻断与边界 | 证据基础 | 置信度 |
| ---- | --------- | ------ | ---- | ---- | -------- | -- | ---- | ---- | ----- | ---- | --- |

### 方向

```text
POSITIVE
NEGATIVE
MIXED
```

方向指外部变量上升或推进时，对目标公司业务状态的主要影响方向。

### 时间范围

```text
IMMEDIATE
WITHIN_QUARTER
ONE_TO_TWO_QUARTERS
MULTI_QUARTER
LONG_TERM
UNKNOWN
```

### 证据基础

```text
正式行业数据
客户明确披露
供应商明确披露
竞争者明确披露
行业卖方研究
多来源共同指向
C3 间接推断
```

### 置信度

```text
HIGH
MEDIUM
LOW
```

置信度反映传导关系的证据强度，不代表事件发生概率。

# 十一、第四部分：行业与商业化里程碑及证明边界

## 1. 定位

里程碑与证明边界应作为独立章节，而不是分散附着在所有驱动中。

原因是：

* 阶段推进本身是产业链研究的重要对象；
* 同一种里程碑可能同时影响多个驱动和候选问题；
* 认证、合同、订单、量产等事件极易被过度外推；
* 下游需要这些材料形成 Realization Factor 的影响边界和可观察接口。

Document2 中的 Realization Factor 要求因素必须具有明确影响边界和可观察性，并且不能保存泛泛经营常识。

## 2. 常见阶段

不同产业可以使用不同阶段，但常见链条包括：

```text
研发或设计
→ 送样
→ 客户测试
→ 客户验证
→ 正式认证
→ 进入供应体系
→ 获得订单分配
→ 量产爬坡
→ 实际出货
→ 收入确认
```

对于资源、医药、航空航天、软件、监管型行业，应根据行业实际情况使用对应里程碑，不机械套用制造业阶段。

## 3. 每个里程碑必须回答

```text
当前处于哪个阶段？
该阶段已经证明了什么？
该阶段仍然不能证明什么？
下一阶段需要什么证据？
什么情况会导致阶段倒退、延迟或失效？
```

例如：

```text
正式客户认证

已经证明：
产品达到客户规定的基本技术和供应资格要求

支持：
进入潜在采购范围
技术可用性提高
供应资格风险下降

仍不能证明：
实际订单规模
最终订单份额
量产良率
按时交付
盈利贡献
```

## 4. 里程碑不得重复成为主体介绍

本部分围绕“阶段及证明边界”组织，而不是围绕公司名称组织。

同一阶段可以引用多个主体作为证据，例如：

* 客户确认；
* 目标公司披露；
* 设备或供应商信号；
* 竞争者对同一平台的进展。

## 5. 输出形式

建议采用“里程碑与证明边界表”：

| 研究对象 | 当前阶段 | 已确认内容 | 尚未证明内容 | 下一可观察证据 | 主要失败或延迟路径 | 证据引用 |
| ---- | ---- | ----- | ------ | ------- | --------- | ---- |

C3 只提供研究材料，不自行生成正式 `RealizationFactor`。

# 十二、第五部分：潜在行业与产业链因素缺口候选

## 1. 定位

这一部分负责：

> **基于当前行业事实、外部主体信号、驱动与分配机制、里程碑证明边界，识别最可能导致未来外部判断发生修正的问题。**

它不是正式 `PotentialGap`。

正式 Potential Gap 需要引用 State 或 Factor、设置 Activation Rule、Market Anchor 和 Invalidation Rule，仍由 Document2 完成。

C3 不判断：

* 当前市场究竟相信什么；
* 某项变化是否已被价格吸收；
* 未来事件是否已经激活 Gap；
* 剩余未定价空间；
* 是否应当交易。

## 2. 候选来源

### 当前事实与主流行业判断的张力

例如：

* 当前需求持续强于原有判断；
* 原预计供需平衡时间正在失效；
* 价格、库存或交付时间与主流判断背离。

### 外部主体之间的张力

例如：

* 客户提高采购，但供应商下调需求预期；
* 竞争者口头判断乐观，却削减资本开支；
* 行业卖方预计产能快速释放，但设备和建设进度持续延迟。

### 主体判断与主体行为的张力

例如：

```text
口头表示需求强劲
vs
实际减少采购或延迟扩建
```

### 短期信号与中长期影响的张力

例如：

```text
竞争者扩产
短期验证需求
vs
中长期增加供给
```

### 行业机会与目标公司分配结果的张力

例如：

* 行业需求增长，但目标公司尚未通过认证；
* 行业价格上涨，但目标公司产品组合不能充分受益；
* 行业短缺，但目标公司自身产能不足；
* 客户采购增加，但竞争者已锁定主要订单。

### 里程碑与经济兑现的张力

例如：

```text
认证不等于订单
订单不等于量产
量产不等于有利润的收入
```

## 3. 纳入条件

一项候选问题应满足以下若干条件：

* 涉及核心外部驱动；
* 能显著影响目标公司订单、ASP、份额、产能或产品阶段；
* 当前主要行业假设的证据仍然薄弱；
* 不同外部主体存在明显分歧；
* 当前正在发生边际变化；
* 未来存在可以观察的事件；
* 分配机制仍不确定；
* 值得下游构造为 State、Factor 或 Potential Gap。

## 4. 候选问题必须双向表达

不得只提出单向利好或利空叙事。

每个候选问题应尽可能说明：

```text
当前外部锚点
可能的上修路径
可能的下修路径
能够确认不同路径的未来事件
影响的目标公司业务状态
当前无法确认的部分
```

## 5. 输出形式

| 字段          | 内容                                        |
| ----------- | ----------------------------------------- |
| 候选问题        | 下游需要继续回答的明确行业或产业链问题                       |
| 当前外部锚点      | 当前事实、主体判断和行业状态                            |
| 涉及的核心驱动     | 引用前文驱动                                    |
| 涉及的分配与传导机制  | 引用前文机制                                    |
| 上修路径        | 哪种变化可能使外部判断上修                             |
| 下修路径        | 哪种变化可能使外部判断下修                             |
| 可观察事件       | 哪些事件能够确认、削弱或否定不同路径                        |
| 可能影响的目标业务状态 | 订单、价格、份额、产能、验证、量产等                        |
| 当前最薄弱环节     | 当前证据和逻辑中最不稳定的部分                           |
| 下游研究需求      | 需要由 Document2 继续形成的 State、Factor 或 Gap 问题 |
| 跨节点验证需求     | C1、C2、O4、外部研究或事件模块                        |
| 证据引用        | DoxAgent 现行引用                             |

候选问题不包含市场定价或交易结论。

# 十三、第六部分：Unknowns、证据边界与跨节点交接

## 1. 目标

这一部分回答：

> 当前 C3 研究中，哪些重要行业和产业链问题无法可靠确认，为什么无法确认，又应交给哪个节点继续处理？

## 2. Unknowns 类型

### 数据缺失

* 行业数据频率过低；
* 数据只覆盖部分区域或产品；
* 价格、库存和订单数据不可获得；
* 客户采购数据未公开；
* 市场份额口径不一致。

### 主体信号冲突

* 主体表述与实际行为不一致；
* 客户、供应商和竞争者给出不同判断；
* 同一主体不同时间的说法发生变化；
* 行业数据与公司口头判断冲突。

### 来源独立性不足

* 多家媒体转载同一产业链传闻；
* 多名分析师实际引用同一非公开来源；
* 信息最初出处无法确认；
* 渠道或竞争者具有明显利益动机。

### 因果归属不确定

* 无法确认客户 Capex 中多少流向目标产品；
* 无法区分补库存和真实终端需求；
* 无法判断扩产属于替换产能还是净新增产能；
* 无法确定价格变化来自需求、成本还是合同重定价。

### 分配机制不确定

* 行业需求增长，但供应商份额未知；
* 客户采购增加，但订单分配未知；
* 目标公司有供应资格，但实际份额未知；
* 行业价格上涨，但目标公司合同条款未知。

### 时间错位

* Capex 宣布时间与设备交付时间不同；
* 设备安装与有效产能形成存在滞后；
* 订单、出货与收入确认位于不同期间；
* 财年和自然年口径不同。

### 里程碑证明不足

* 送样来源不可靠；
* 客户验证没有正式确认；
* 认证范围不清晰；
* 合同是否具有约束力未知；
* 订单规模、交付时间或盈利条件未知。

## 4. 输出形式

| Unknown 或交接问题 | 无法确认的原因 | 影响的研究主线 | 所需证据 | 建议交接节点 | 对当前结论的影响 |
| ------------- | ------- | ------- | ---- | ------ | -------- |

Unknowns 只能降低相关判断的确定性，不应阻止报告继续生成。

# 十四、C3 与其他节点的最终边界

## 1. C3 与 C1

```text
C3：
外部变量
→ 行业及产业链机制
→ 分配机制
→ 目标公司业务状态

C1：
目标公司业务状态
→ 收入、利润、现金流和财务结构
```

C3 可以研究目标公司的：

* 订单；
* ASP；
* 市场份额；
* 客户认证；
* 产能利用率；
* 产品及商业化阶段。

但不负责完整解释这些变量如何转化为 EPS、FCF 和估值。

## 2. C3 与 C2

C2 研究广义宏观与金融环境。

C3 研究这些环境是否具体转化为：

* 行业需求；
* 客户采购；
* 供给变化；
* 价格；
* 库存；
* 产业链行为。

例如：

```text
C2：
金融条件收紧

C3：
云厂商是否因此削减数据中心 Capex，
以及削减是否影响目标产品采购
```

## 3. C3 与 O4

C3 不分析：

* 同业股票涨跌；
* 同业估值；
* 行业资金轮动；
* 目标公司是否已被重估；
* 某项行业变化是否已经 priced in。

## 4. C3 与外部研究

外部研究回答：

```text
谁与目标公司相关？
有哪些关系、暴露和未来事件？
```

C3 回答：

```text
当前哪些关系最重要？
这些关系正在发生什么变化？
变化通过什么机制影响目标公司？
```

## 5. C3 与 Document2

C3 提供：

```text
事实
信号
驱动
分配机制
传导关系
里程碑证明边界
候选问题
Unknowns
```

Document2 将这些材料组织为：

```text
Expectation State
Realization Factor
Potential Gap
```

这是软限制，不是阻塞性校验。

# 十八、C3 的最终输出逻辑

重构后的 C3 不再回答：

> 这个行业是否值得投资，哪些公司更有竞争优势，应该买哪只股票？

它依次回答：

```text
与目标公司相关的外部行业和产业链状态是什么
        ↓
重要客户、供应商和竞争者说了什么、做了什么
        ↓
这些信号相互支持还是存在矛盾
        ↓
哪些外部变量真正驱动行业变化
        ↓
需求、订单、供给、价格和份额如何分配
        ↓
这些变化最终影响目标公司的什么业务状态
        ↓
当前产业链进展处于什么阶段
        ↓
现有里程碑证明了什么，又没有证明什么
        ↓
哪些外部假设最脆弱、最可能被未来事件修改
        ↓
下游应继续构造和验证哪些预期问题
```

最终核心产物为：

```text
目标相关的行业与产业链事实基准
关键外部主体判断与行为信号
核心外部驱动及跨主体证据
行业分配机制与目标公司传导关系
关键里程碑及证明边界
潜在行业与产业链因素缺口候选
Unknowns 与跨节点交接需求
```
