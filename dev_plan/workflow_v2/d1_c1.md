# C1 个股基本面研究重构架构

## 一、C1 的最终定位

C1 是预期研究之前的公司基本面研究节点。

它不负责：

* 直接构造 `Expectation Unit`；
* 生成正式的 `RealizationFactor`；
* 生成或激活 `PotentialGap`；
* 判断新闻是否形成真实预期差；
* 判断某项变化是否已经被市场定价；
* 给出目标价、交易建议或买卖结论。

C1 的职责是：

> **基于公司披露、基础预期指标、管理层和卖方材料，解释公司的当前基本面由什么驱动、关键变量如何转化为财务结果，以及哪些公司侧基本面假设最值得下游继续研究。**

下游方案本身已经将 C1 的贡献定义为实际财务、管理层指引、公司业务状态和财务转化，同时要求领域 Agent 为兑现条件、阻断点和潜在修正方向提供研究材料，但最终对象仍由 O1 统合。

因此，C1 的核心成果应固定为：

```text
公司侧事实和预期基准
+
核心驱动因子
+
关键变量传导关系
+
潜在基本面因素缺口候选
+
Unknowns 与证据边界
```

---

# 二、C1 与基础预期指标采集的关系

基础预期指标采集已经负责维护：

* 公司实际财务指标；
* 管理层指引；
* 卖方一致预期；
* 核心经营 KPI；
* 统一 `metric_id`；
* `StateParameter`；
* `StateValue`；
* 现行证据引用。

C1 报告不得另建参数目录，也不得把基础预期指标重新完整抄写成一张指标表。

二者分工为：

```text
基础预期指标采集
回答“当前有哪些标准化数值和状态”

C1 基本面研究
回答“为什么是这个状态、什么驱动了变化、
这些状态之间怎样关联、未来可能如何改变”
```

C1 可以直接引用现有 `metric_id` 和 DoxAgent 引用对象，但不新增一套持久化的：

```text
DriverParameter
TransmissionParameter
FundamentalStateBook
```

核心驱动因子、传导链和潜在缺口候选都是本次研究报告中的分析产物，而不是另一套状态 Registry。

---

# 三、C1 最终报告结构

C1 报告不设置开头摘要。

最终固定为六个部分：

```text
1. 近期基本面状态与变化
2. 管理层与卖方当前预期
3. 核心驱动因子
4. 关键变量传导链
5. 潜在基本面因素缺口
6. Unknowns 与证据边界
```

其逻辑顺序是：

```text
现实发生了什么
        ↓
管理层和卖方预计什么
        ↓
什么因素在驱动现实和未来
        ↓
这些因素如何转化为财务结果
        ↓
哪些基本面假设最脆弱、最敏感
        ↓
还有哪些问题无法确认
```

---

# 四、第一部分：近期基本面状态与变化

## 1. 目标

这一部分建立公司侧的事实基准，回答：

> 最近一个主要报告周期内，公司的经营、盈利、现金流和资产负债表究竟发生了哪些实质变化？

它不是完整复述财报，也不按照利润表、资产负债表和现金流量表逐章展开。

只写对当前公司基本面判断具有实质意义的变化。

## 2. 必须分析的内容

### 经营状态变化

包括：

* 合并及主要分部收入变化；
* 核心经营 KPI 变化；
* 销量、价格、客户、订单、产品组合或产能变化；
* 主要业务之间的增长差异。

### 盈利状态变化

包括：

* 毛利率；
* 营业利润率；
* 费用结构；
* GAAP 与 Non-GAAP 差异；
* 一次性项目；
* 盈利改善或恶化的主要来源。

### 现金与资本状态变化

包括：

* 经营现金流；
* 自由现金流；
* 资本开支；
* 营运资本；
* 现金、债务及融资需求；
* 股权稀释或回购。

### 多锚点比较

对关键结果尽可能比较：

```text
实际值 vs 上期实际值
实际值 vs 管理层原有指引
实际值 vs 卖方一致预期
```

这些比较值优先读取基础预期指标采集结果。

## 3. 输出形式

建议使用“重大状态变化表”：

| 变化项目      | 最新状态   | 比较锚点       | 变化来源               | 持续性判断      | 证据引用          |
| --------- | ------ | ---------- | ------------------ | ---------- | ------------- |
| 具体指标或经营状态 | 当前值或方向 | 上期、指引或卖方预期 | 价格、销量、组合、费用、一次性项目等 | 持续、暂时或尚不确定 | DoxAgent 现行引用 |

其中“持续性判断”只说明公司侧证据是否支持延续，不判断市场是否已经定价。

## 4. 与核心驱动部分的边界

本部分回答：

> 什么变了？

核心驱动因子部分回答：

> 为什么变，以及未来还可能由什么继续驱动？

本部分不得提前展开完整传导链，以避免重复。

---

# 五、第二部分：管理层与卖方当前预期

## 1. 目标

这一部分回答：

> 管理层和卖方分别在假设公司未来会发生什么？

当前真实 C1 输出已经能够提取收入、EPS 指引以及管理层对 PC 需求的判断，但这些信息目前只是财报章节中的附属内容，没有被组织成公司侧预期基准。

## 2. 管理层预期

需要覆盖：

* 正式数值指引；
* 中长期经营或财务目标；
* 产品、产能、量产、客户和交付时间表；
* 资本开支和现金流计划；
* 管理层对需求、价格、成本和利润率的方向判断；
* 与上一次披露相比的上修、下修或表述变化；
* 正式指引背后的主要经营假设。

必须区分：

```text
正式数值指引
明确的方向性预期
长期战略目标
管理层一般性乐观表述
```

四者不能被当成同等强度的管理层预期。

## 3. 卖方预期

需要覆盖：

* 主要财务指标一致预期；
* 与公司核心经营驱动直接相关的卖方预测；
* 近期预测修正方向；
* 预测分歧所在；
* 卖方模型中的关键公司侧假设；
* 卖方是否接受管理层的主要经营假设。

卖方部分不以评级和目标价汇总为中心。

分析师评级、目标价高低和估值倍数主要属于 O4；C1 关注的是分析师在公司收入、利润、现金流和经营 KPI 上具体假设什么。

## 4. 输出形式

建议使用“预期对照表”：

| 预期主题          | 时间范围       | 管理层预期    | 卖方预期      | 最近变化        | 主要假设          | 证据引用 |
| ------------- | ---------- | -------- | --------- | ----------- | ------------- | ---- |
| 收入、利润率、产能、交付等 | 季度、年度或产品周期 | 正式或方向性表述 | 一致预期或主流预测 | 上修、下修、稳定或分化 | 预测成立所依赖的公司侧条件 | 现行引用 |

这一部分可以如实呈现管理层与卖方之间的差异，但不在此处直接将差异定义为 Gap。

# 六、第三部分：核心驱动因子

## 1. 目标

这一部分回答：

> 当前及未来几个季度，哪些少数因素真正决定公司的收入、利润率、现金流和财务结构？

核心驱动因子分为：

```text
当前结果型驱动因子
长期基本面驱动因素
```

只有主线因子进入正式报告。

普通背景信息、低影响变量和无法说明财务意义的公司新闻不得进入核心驱动部分。

## 2. 主线因子的判断标准

一个因素应满足以下若干条件，才作为核心驱动因子：

* 对收入、利润率、资本开支或现金流影响较大；
* 能解释近期主要财务变化；
* 当前存在明显边际变化；
* 未来可能显著改变公司财务状态；
* 管理层或卖方持续关注；
* 可以通过公司披露或公开指标持续观察；
* 对其方向、持续性或财务转化存在不确定性。

不要求机械打分，但 Agent 必须解释为什么该因素属于主线。

---

## 3. 当前结果型驱动因子

当前结果型驱动用于解释最新财务结果为什么发生变化。

常见来源包括：

* 产品价格；
* 销量或出货量；
* 产品组合；
* 客户或区域结构；
* 产能利用率；
* 单位成本；
* 原材料和制造成本；
* 研发及销售费用；
* 重组、减值或其他一次性项目；
* 营运资本变化；
* 资本开支变化。

对每个结果型驱动，必须说明：

```text
驱动因子是什么
当前方向如何
它解释了哪些财务变化
依据是公司直接披露还是分析推断
该影响是持续性的还是一次性的
```

不能因为某项指标发生变化，就自动把它列为驱动因子。它必须能够解释重要的财务结果。

---

## 4. 长期基本面驱动因素与边界

长期驱动因素是：

> 当前尚未完全反映在当期财务结果中，但可能在未来多个季度改变公司收入、成本、利润率、资本需求或现金流结构的变量。

例如：

* 产能扩张；
* 新产品路线图；
* 客户认证；
* 业务商业化；
* 规模效应；
* 技术升级；
* 成本曲线变化；
* 新客户或新区域进入；
* 资本配置转变；
* 长期合同和订单可见度。

长期驱动因素必须同时说明其基本面边界。

即：

```text
为什么它可能推动基本面改善
+
为什么不能将改善无限外推
```

可能的边界包括：

* 需求无法吸收新增供给；
* 技术或良率不达标；
* 客户认证延迟；
* 订单规模不足；
* 竞争者同步扩产；
* 价格下降抵消销量增长；
* 资本开支吞噬自由现金流；
* 融资或资产负债表能力不足；
* 新业务收入无法形成利润；
* 管理层历史执行能力不足。

---

## 5. 兑现能力与公司侧约束

兑现能力不单独成为一个庞大的公司质量章节，而是附着在每个核心驱动因子下面。

对每个驱动因子，C1 都需要回答：

> 公司是否有能力将这一变量真正转化成收入、利润和现金流？

主要分析：

### 经营执行能力

* 产品能否按计划推出；
* 产能和交付能力是否足够；
* 良率、技术或运营水平是否达标；
* 客户导入和商业化是否顺利；
* 管理层过去是否完成类似目标。

### 财务承受能力

* 现金和融资是否支持相关投资；
* 资本开支是否过高；
* 兑现延期是否会导致流动性或稀释风险；
* 资产负债表能否承受失败或延迟。

### 盈利转化能力

* 收入增长是否产生毛利；
* 毛利是否转化成营业利润；
* 营业利润是否转化成现金流；
* 增量收入是否依赖持续高资本投入。

### 结构性约束

* 技术；
* 成本；
* 产能；
* 客户认证；
* 定价权；
* 客户集中；
* 竞争地位；
* 监管许可。

---

## 6. 每个驱动因子的固定表达结构

| 字段        | 内容                   |
| --------- | -------------------- |
| 驱动因子      | 自然语言名称，不另建持久化参数      |
| 类型        | 当前结果型 / 长期基本面型       |
| 当前状态与边际方向 | 当前证据显示其改善、稳定、恶化或尚不明确 |
| 为什么是主线    | 它对公司主要财务结果的重要性       |
| 已反映的财务影响  | 当前已经影响哪些财务结果         |
| 未来可能影响    | 后续可能影响哪些业务或财务状态      |
| 兑现能力与约束   | 公司能否将其转化，以及主要限制      |
| 长期边界      | 仅长期驱动因素填写            |
| 观察依据      | 基础指标、公司披露、管理层或卖方材料   |
| 证据引用      | DoxAgent 现行引用        |

驱动因子名称是报告级分析标签，不进入基础预期指标 Registry。

---

# 七、第四部分：关键变量传导链

## 1. 目标

这一部分回答：

> 某个核心业务变量变化以后，会通过什么主要路径影响收入、利润率、费用、资本开支、EPS 和自由现金流？

它不是完整财务模型，也不要求生成精确的盈利贡献。

它提供的是一副简化的：

```text
业务变量
→ 直接经营影响
→ 财务结果
```

的传导骨架。

## 2. 传导关系需要覆盖的财务终点

根据公司业务实际情况，分析变量可能影响：

* 收入；
* 毛利率；
* 营业费用；
* 营业利润；
* EPS；
* 营运资本；
* 资本开支；
* 自由现金流；
* 债务和融资需求。

不要求每条链都覆盖所有财务指标。

## 3. 不进行虚假精确归因

C1 应当区分三种归因层级。

### 第一层：财务层面可确认

例如：

* 利润改善主要来自毛利率，而非费用率下降；
* 自由现金流恶化主要来自资本开支上升；
* 收入增长集中在某一分部。

### 第二层：业务解释有明确支持

例如：

* 管理层明确表示 ASP 和产品组合推动毛利率改善；
* 公司披露新增客户带动某分部收入。

### 第三层：间接推断

例如：

* 某项新产品可能是毛利率改善的重要来源；
* 某项涨价可能部分抵消销量下降。

若公司没有披露，C1 不得强行计算：

* 某一产品精确贡献多少利润；
* 某次涨价精确贡献多少毛利；
* 多个经营因素分别贡献多少百分点。

---

## 4. 传导表的固定结构

每一行只描述一条主要传导关系：

| 上游业务变量 | 直接经营影响 | 财务指标 | 方向 | 影响强度 | 时间滞后 | 成立条件 | 阻断因素 | 证据基础 | 置信度 |
| ------ | ------ | ---- | -- | ---- | ---- | ---- | ---- | ---- | --- |

### 方向

```text
POSITIVE
NEGATIVE
MIXED
```

方向表示上游变量上升或推进时，对目标财务指标的主要影响方向。

### 影响强度

```text
HIGH
MEDIUM
LOW
UNKNOWN
```

它是相对重要性判断，不是精确敏感性系数。

### 时间滞后

```text
IMMEDIATE
WITHIN_QUARTER
ONE_TO_TWO_QUARTERS
MULTI_QUARTER
LONG_TERM
UNKNOWN
```

### 置信度

```text
HIGH
MEDIUM
LOW
```

置信度根据证据决定：

* 公司明确披露或财务拆解可直接确认：较高；
* 管理层与多项数据共同支持：中等；
* 主要依靠间接解释：较低。

### 证据基础

必须说明关系主要基于：

```text
公司财务披露
管理层明确解释
财务数据拆解
卖方主流分析
多来源共同指向
C1 间接推断
```

传导表必须附带现行证据引用，不再建立独立 Transmission Registry。

---

# 八、第五部分：潜在基本面因素缺口

## 1. 定位

这一部分不确认真实的 Expectation Gap。

它负责：

> **识别最容易导致未来预期修正的公司侧基本面问题，并整理为下游继续研究的候选问题。**

C1 不判断：

* 市场当前到底定价了多少；
* 某个问题是否已经构成可交易差异；
* 某一新闻是否已激活 Gap；
* 事件后的剩余未定价部分。

下游定义中，Potential Gap 是基于当前 State 和 Realization Model 形成的条件性预期修正假设，而非公开数据之间的静态差异。

C1 此处仅提供其公司基本面来源材料。

---

## 2. 预期张力作为扫描视角

预期张力不单独设置章节，而是作为发现潜在缺口的扫描方法。

C1 需要检查：

### 实际结果与原有预期

* 实际值是否持续偏离原有管理层或卖方预期；
* 超预期或低于预期的原因是否具有持续性。

### 管理层与卖方

* 卖方是否比管理层更乐观或更悲观；
* 两者是否对同一经营变量使用了不同假设；
* 卖方预测是否依赖管理层尚未证实的目标。

### 业务进展与财务转化

* 产品、订单或客户进展是否尚未形成收入；
* 收入增长是否尚未形成利润；
* 利润改善是否尚未形成现金流。

### 短期改善与长期结构

* 短期改善是否来自一次性因素；
* 当前趋势是否真正改变长期成本、份额或资本回报结构。

### 增长机会与公司兑现能力

* 机会是否超过公司产能、技术、资金或交付能力；
* 公司是否有能力获得行业增长，而不只是暴露于行业增长。

### 管理层目标与可观察进度

* 管理层目标是否有相应资本投入、客户进度或经营数据支持；
* 时间表是否与当前进展一致。

若某项张力需要产业链、宏观或市场定价信息才能确认，C1 只能标记为待外部验证，不得自行补全。

---

## 3. 潜在缺口候选的纳入条件

一项问题进入本部分，应至少具备以下特征中的若干项：

* 涉及核心驱动因子；
* 对收入、利润率、现金流或资本需求影响较大；
* 当前主要假设的证据仍然薄弱；
* 管理层与卖方存在明显差异；
* 对财务结果具有较高弹性；
* 当前正在发生边际变化；
* 尚未被当期财务结果充分反映；
* 公司兑现能力或结构性边界尚未得到验证；
* 值得下游结合 C2、C3、O4 或事件研究继续追问。

普通财务风险、泛泛不确定性和所有公司都存在的经营常识，不进入候选清单。

---

## 4. 每个候选问题的固定输出形式

| 字段        | 内容                            |
| --------- | ----------------------------- |
| 候选问题      | 后续预期研究需要回答的明确问题               |
| 涉及的核心驱动   | 引用前文驱动因子                      |
| 涉及的传导关系   | 引用前文传导链                       |
| 当前基本面事实   | 当前能够确认的公司侧状态                  |
| 当前主要假设    | 管理层、卖方或当前研究依赖的假设              |
| 张力来源      | 实际/预期、管理层/卖方、短期/长期、业务/财务转化等   |
| 最薄弱环节     | 当前证据或传导路径中最不稳定的部分             |
| 潜在修正方向    | UPSIDE / DOWNSIDE / TWO_SIDED |
| 可能影响的财务结果 | 收入、利润率、EPS、FCF、资本需求等          |
| 后续研究重点    | 下游需要进一步验证的问题                  |
| 外部验证需求    | C2、C3、O4、事件模块或外部研究            |
| 证据引用      | DoxAgent 现行引用                 |

### 示例表达

> 当前毛利率改善主要得到价格和产品组合支持，但公司计划中的新增产能可能在未来改变供给和成本结构。后续需要研究新增产能对价格中枢、利用率及自由现金流的净影响，以及卖方当前预测是否充分考虑这一约束。

这是潜在基本面因素缺口候选，不是正式 Gap，也不包含 priced-in 结论。

---

## 5. 验证事项如何处理

不再单独设置“近期关键验证点”章节。

需要观察的公司披露、经营数据或里程碑，分别进入：

* 核心驱动因子的“观察依据”；
* 变量传导链的“成立条件和阻断因素”；
* 潜在缺口候选的“后续研究重点”。

每项验证事项必须说明：

```text
它能够确认什么
它可能修改什么基本面假设
它仍然不能证明什么
```

例如：

```text
官方确认外部客户
→ 支持客户导入和未来需求假设
→ 可能影响收入、利用率和亏损收窄路径
→ 但不能单独证明订单规模、良率和利润贡献
```

# 九、第六部分：Unknowns 与证据边界

## 1. 目标

这一部分回答：

> 当前 C1 研究中，哪些重要问题因为数据、口径或职责边界而无法可靠确认？

## 2. Unknowns 类型

### 数据缺失

* 公司没有披露的经营 KPI；
* 卖方预测不可获得；
* 分部或产品口径不足；
* 历史口径发生变化。

### 归因不确定

* 无法精确拆分不同产品的收入或利润贡献；
* 无法区分多个业务变量的独立影响；
* 一次性与持续性影响无法完全分离。

### 预期口径不一致

* 管理层与卖方使用不同财务口径；
* 时间范围不同；
* GAAP 与 Non-GAAP 不可直接比较；
* 管理层方向性表述无法与卖方数值直接比较。

### 证据冲突

* 不同管理层表述不一致；
* 公司披露与卖方解释存在差异；
* 多个来源对同一经营状态给出不同判断。

### 职责边界

* 行业供需、客户和竞争者状态需要 C3；
* 宏观、政策和融资环境需要 C2；
* 估值、期权、仓位和市场吸收需要 O4；
* 复杂实体关系和催化剂可观察性需要外部研究；
* 真实 Gap 与市场定价比较需要下游。

## 3. 输出形式

| Unknown | 无法确认的原因 | 影响的驱动或传导链 | 所需证据 | 建议交接节点 | 对当前判断的影响 |
| ------- | ------- | --------- | ---- | ------ | -------- |

Unknowns 只能降低相关结论的确定性，不应阻止报告继续生成。

# 十、旧 Skill 的最终调整

当前 Skill 同时强制执行财务健康评分、完整估值、目标价、五类护城河和管理层质量评分，容易把 C1 拉回传统启动报告。

## 1. 删除的固定输出

删除：

```text
开头摘要
近期催化剂独立章节
Financial Health Score
Earnings Quality 三级标签
固定财务风险数量要求
完整 DCF
DDM
目标价
高估 / 低估判断
Margin of Safety
完整估值矩阵
五类护城河评分
管理层综合评分
投资建议
priced-in 判断
```

当前 INTC 输出中的完整估值章节、财务健康评分和最终操作建议均不再属于 C1 核心输出。

## 2. 保留为后台分析方法

保留但不作为固定报告结构：

* 三张财务报表分析；
* 盈利质量分析；
* 多年财务趋势；
* 分部分析；
* 同业经营指标比较；
* 管理层历史执行能力；
* 资本配置；
* 成本、规模、技术和客户黏性分析。

这些方法用于支持核心驱动、传导链和长期边界，而不是各自生成独立章节和评分。

## 3. 估值的边界

C1 可以讨论：

* 哪些基本面变量可能改变盈利持续性；
* 哪些变量会改变合理估值所依赖的财务基础；
* 当前卖方模型依赖什么增长和利润率假设。

C1 不负责：

* 计算市场估值状态；
* 选择估值倍数；
* 判断当前估值昂贵或便宜；
* 给出合理价值；
* 判断基本面变化是否已经反映在价格中。

# 十一、最终 C1 Skill 骨架

```text
Task

围绕公司当前和未来基本面，
研究近期事实状态、管理层与卖方预期、
核心驱动因子、业务到财务的传导关系，
以及最值得下游继续研究的潜在基本面因素缺口。

基础预期指标采集结果是主要定量输入。
不得另建参数目录，也不得机械重复全部基础指标。

Required Report Structure

1. Recent Fundamental State and Changes
2. Management and Sell-Side Expectations
3. Core Fundamental Drivers
   - Current Result Drivers
   - Long-Term Drivers and Boundaries
   - Execution Capacity and Company-Side Constraints
4. Key Variable Transmission Chains
5. Potential Fundamental Factor Gaps
6. Unknowns and Evidence Boundaries

Core Requirements

- 区分事实、管理层预期、卖方预期和分析推断；
- 只保留公司基本面的主线驱动；
- 将兑现能力与约束附着到具体驱动因子；
- 用传导表说明业务变量如何影响财务结果；
- 不进行没有披露依据的精确业务利润归因；
- 将预期张力作为发现潜在缺口的扫描视角；
- 潜在缺口只能输出候选问题，不得输出正式 Gap；
- 所有重大判断使用 DoxAgent 现行引用系统。

Prohibited Outputs

- Expectation Unit
- Realization Factor object
- Potential Gap object
- Gap Activation
- Market Absorption
- Priced-in conclusion
- Full DCF or target price
- Overvalued / undervalued conclusion
- Trading recommendation
- Formulaic financial, moat or management scores
```

# 十二、C1 的最终输出逻辑

重构后的 C1 不再回答：

> 这家公司基本面好不好，股票值多少钱，应不应该买？

它依次回答：

```text
最近公司的基本面实际发生了什么
        ↓
管理层和卖方当前分别预计什么
        ↓
什么因素在驱动当前和未来基本面
        ↓
这些变量怎样转化为收入、利润和现金流
        ↓
公司是否具备兑现能力，边界在哪里
        ↓
哪些基本面假设最薄弱、最敏感
        ↓
下游还应继续研究哪些问题
```

最终核心产物为：

```text
近期公司侧事实和预期基准
核心驱动因子及长期基本面边界
关键变量传导表
潜在基本面因素缺口候选清单
Unknowns 与跨节点交接需求
```
