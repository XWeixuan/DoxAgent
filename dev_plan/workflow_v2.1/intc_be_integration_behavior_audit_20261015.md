# INTC / BE D3 Integration行为审查（2026-10-15）

## 结论

Integration确实在检查trigger boundary，并对最终criterion/calibration作了可验证的实质修改。主要行为是找出过严的共同确认、过晚的结果门槛、阈值缺依据、已有预期与新事实混淆、方向/对象错误，以及校准与判定字段不一致。不能把它概括为只做泛化或只补资料。

但无法确认每条发布规则的经济充分性都已合理：INTC四个final edit未完成且整份旧稿回退保留；两案44/55项remaining_gaps；一些修复从硬阈值改成“重要/实质”而未给完整ticker层比较。当前更多在防止漏掉较早可公开的重要入口，与对整套主题的边缘性筛除是不同任务。没有真实消息回放或独立交易效果验证，本报告不声称其已通过该层验收。

## 为什么补研

1. **原题/D2中的重要入口只在scope或transmission，不在实际Conditions。** INTC PC配套只剩CPU降档/替换，缺“不降CPU但缺组件、提价导致延购”；BE许可全限Jupiter全规模，漏其他站点本地有效限制；非CPU价格、Foundry报价/NRE、服务收费同样只作背景。补研在试图补回入口，未必发现新主题。
2. **只能证明强情景，尚未建立最早相邻充分状态。** INTC百万台/整12月换机、ASIC须整代退出；BE韩国一年延期、全新增1GW撤回、燃料保护180MW完整24个月。要求查是否较小但有分量的部分或较早权利/概率变化已经足够。
3. **人为阈值由历史数或算例推来，缺公司/项目比较。** BE同线20%吞吐不等全厂0.4GW，韩国统一50MW不来自实际本地项目9/10/31/40MW；INTC板面积20%只是敏感性，不证明交易分量。补研不等于保证删数字，而是找成立比较。
4. **未来消息难以公开需要的内部净量。** INTC要求CPU专属BOM溢价、内部ASIC量/利润、组件库存；BE要求原ASP、全部发票/税权益金额、活跃服务费总表。研究可行公开锚，不能靠等最终业绩掩盖未知。
5. **当前预期/事实基线尚未核清。** INTC Gaudi维护矩阵可能已存在；BE竞争FCE 100MW属于已计划路径，不自动是新SHORT；AEP by/before2028存在实际语言区别，需原文核实。
6. **方向到ticker的联系不闭合。** 制造外包可减资本又减内部机会，模块少换不自动净收益，热备用不自动减磨损，伙伴资金回收不自动Bloom受益。要研究主导联系而非强行晚触发。
7. **来源侧覆盖回看发现遗漏。** INTC外币资本/套保、BE原资本用途零规则Topic被再次核实；也有“研究后仍零Policy”的真实结论，不是要求所有补研必产规则。

例：INTC非CPU独立价格/供给、ASIC部分扩缩、外汇套保三项补研都未形成Policy；gap明确说明没闭合比较，不以集团总额或衍生名义本金冒充独立净风险。

## 为什么直接edit_request

与补研的分界是“已有材料足以知道怎么改”还是“连替代边界仍未知”。常见直接编辑包括：

- 去掉无必要确认包：Windows Arm任务解锁不必同次新增OEM默认配置；Intel进入外购加速器生产不必另一独立供应商同时生产；临时电源有效停运决定不必等客户已经停机。
- 修正确认过晚/范围过满：Gaudi不必三个地区同时GA；已有Bloom阶段关键融资关闭不要求新增MW；Xeon推理容量损失不须连系统主机全部退出Intel。
- 修正方向与对象：AMD EPYC净价上涨不能代Xeon净价上涨；换虚拟化软件栈不等离开Intel；信用担保不等弥补现金延后。
- 将真实边界落到criterion：INTC净价原criterion任意上涨，calibration约10%/范围/执行比较；BE制造原criterion任意合格产能，calibration限定时间/数量。编辑明确对齐，而非只润色说明。
- 修事实、期间、层级：FERC12月3日并非保证最终批准；燃料电池无燃烧但可产生CO2；CPO供应商角色分配的layer OUTER改MIDDLE。
- 合并版本/保留身份和有效入口：大量“合并”是主稿与其同ID补研稿协调，不等于两个独立主题压成一个；同时移除新稿误删的有效Condition。

## 没有做到的部分

### 明确的执行失败

INTC跨厂芯粒、先进制造抵免、股权融资每股权益、Secure Enclave四份final文件均出现 `unknown explicit Condition ID; new Conditions must omit ID`。宿主不接纳错误新身份，最终四条Policy与basis整份相同，Conditions也完全相同。因此Review提出的相应修正并未落地，不能用任务COMPLETED或总体exit0抵销。

跨厂芯粒最直观：Review要求删除“此前从未属于Intel的非Intel闭环一出现即SHORT”的推断；最终旧C2仍可仅凭替代闭环不允许客户交独立封装商集成而触发，没有实际原有Intel角色/可争取机会损失的必要比较。相邻CPO稿成功修复，不代表该稿也修复。

### 经济充分性仍有限

- 44/55条remaining_gaps明确指出价格、成本、部分规模和早期机会比较未建立。它们不等同44/55个技术失败，也不说明其他所有条件均错。
- 部分条件移除任意数字后用“重要/有分量/实质”表达，形式上更灵活，仍须有ticker层可识别暴露和预期比较，否则W3需临场补判断。
- BE核心制造降本分支最终未保留：5%改善尚不能证明超既有持续降本预期；这说明节点会拒绝未成立分支，但也说明补研不保证补齐。
- 对外围主题本身应否拥有独立交易席位的审查较弱。一个低重要性主题的criterion可以被修得可判、无重复确认，而仍不是值得独立发布的主题。
- 未进行真实消息命中/误报/漏报回放，也未独立重查所有外部原始数据，所以本次只能确认审查内容、改稿落地与明确缺口，不提供整体“边界合理率”。

总体判断：**O3真正做了边界检查，且不少改动能在最终条件中验证；没有全面做到、也没有足够证据证明整套边界均合理。其显著偏好是补回外侧、较早、可公开的独立入口，后续仍需要同等力度判断ticker重要性与最终主题独立价值。**
