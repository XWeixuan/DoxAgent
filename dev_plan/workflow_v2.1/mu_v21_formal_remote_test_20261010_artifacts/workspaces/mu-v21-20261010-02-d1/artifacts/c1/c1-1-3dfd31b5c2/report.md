## 三、核心基本面驱动因子

### 核心驱动概览
- **D1：DRAM/NAND 可实现售价与供需紧张度｜CURRENT_RESULT**——解释本轮收入及利润的最大已披露变化。
- **D2：AI 数据中心产品采用与有限供给的产品配置｜CURRENT_RESULT**——解释出货去向、业务增量及组合；与 D1 的 ASP 含义部分重叠，不相加归因。
- **D3：多年战略客户合同的覆盖与履约｜LONG_TERM_FUNDAMENTAL**——管理层提出的业务稳定性机制，尚未证明跨周期利润底线。
- **D4：单位晶圆有效供给及瓶颈扩产｜LONG_TERM_FUNDAMENTAL**——连接制程、良率、封装和新增工厂的规模/成本能力；边界是再投资和合格产出，而非建设面积。

### D1：DRAM/NAND 可实现售价与供需紧张度
- **现状及已反映部分（报告事实）**：全年 DRAM/NAND ASP 分别约增加 180%/200%，出货均增至 20% 中段；公司将毛利改善主要归于售价，另有组合与降本。跨业务单元普遍涨价，是比“HBM 独自带动利润”更符合披露的解释。【cite:O57】
- **边际方向**：最新 Q4 GAAP 毛利率仍上升，但 FY2027 Q1 指引低于 Q4。这是高利润平台上仍存在波动的证据，不是价格反转的直接证据。【cite:O44】
- **执行与限制**：公司称需求增长超过自身及行业增加供给的能力，并进行供应配置；这一供需判断属于公司解释，行业竞争者增量、客户库存与合约/现货报价尚需 C3 核实。【cite:O57】本轮无法把报价变化与产品结构影响从 ASP 中完全分离。
- **判断强度**：本期价格主因 HIGH；紧张度能维持多久 Unknown。公司现金能力较强但不能阻止行业价格周期，历史涨价幅度不是长期增长率。

### D2：AI 数据中心产品采用与有限供给的产品配置
- **现状及已反映部分**：Q4 CDBU 是最大收入环比增量来源；CMBU 同时包含 HBM、DDR 和 LPDDR，不能以 CMBU 营收代替 HBM 营收。FY2026 HBM 出货多数仍为 HBM3E 12-high；HBM4 36GB 已量产、48GB 为送样。SOCAMM 收入环比超过翻倍、6600 ION 放量及新 SSD 出货有直接产品进展支持。【cite:O44】【cite:O88】
- **为何重要（C1 判断）**：工作负载使产品带宽、容量及能效成为客户采用条件，供应分配决定哪些业务能交付。MCBU 全年数量减少但收入增加，说明终端需求数量、可供数量和收入变化需要分别观察。【cite:O57】
- **执行与限制**：公司披露 HBM4 逻辑底层 die 与 DRAM 核心 die 内部设计制造，包装/测试及客户认证都是公司执行环节；认证、设计获胜、送样和量产分别报告，不能将任一阶段自动换算为最终收入。【cite:O88】【cite:O44】受限供给意味着提高一种产品的占比可能挤出其他业务，而非全部产品独立放量。
- **判断强度**：产品进展和业务单元贡献 HIGH；单品收入、良率、每客户供应比例及利润贡献 Unknown。“高价值产品占比提高必然提高毛利”的单品推断仅 LOW，不据此计算 HBM 利润贡献。

### D3：多年战略客户合同的覆盖与履约
- **现状（报告事实）**：已有多年 take-or-pay 数量承诺，定价固定或定期协商，多数含上下限；127.47 亿美元保证金已到账，但属于融资现金流，几乎全部安排在 2029—2031 年返还。70 亿美元信用证已签发或承诺，取用依赖违约条件。【cite:O57】【cite:O31】【cite:O44】
- **机制与长期边界**：管理层认为价格底线及数量承诺增强可预测性，并预计合同底价毛利显著超过旧周期峰值；这是明确方向性预期，不是已证实的公司合并利润下限。【cite:O57】C1 判断：协议的长期意义取决于覆盖量、产品范围、价格重谈、履约及成本变化；价格上限也可能约束上行。已收保证金不能代表整个合同的收入、利润或新增可自由分配资本。
- **执行与财务限制**：承诺供给要求持续制造、认证和资本投入；未来退还保证金需要现金安排，违约保护也不能替代合格交付。现有流动性提供缓冲，但未取得协议产品分布与违约情景的财务影响。
- **判断强度**：合同形式及现金分类 HIGH；跨周期利润稳定性 MEDIUM（管理层观点），覆盖全部公司的结论 Unknown。

### D4：单位晶圆有效供给及瓶颈扩产
- **现状及已反映部分**：1γ 已占 Q4 DRAM 比特产量多数，G8/G9 是 FY2026 NAND 主要节点；公司披露制程提高单位晶圆比特密度、降低单位比特制造成本，全年毛利已包含制造降本，但未量化各节点贡献。【cite:O88】【cite:O57】
- **长期能力与边界**：HBM4E 及分期晶圆/封装项目提供进一步改进能力；目前新加坡封装、Idaho 首厂、铜锣新产出仍为日历 2027 计划。公司通常使用全部既有制造能力，但新厂初始晶圆不等于经济良率、客户认证或商业满产。【cite:O31】【cite:O57】【cite:O88】
- **执行限制**：设备、制程转换、封装测试和客户认证须共同匹配；只解决洁净室空间不证明最终可售产品同步增加。产品性能、良率及成本还受技术复杂度与竞争制约。【cite:O88】
- **资金与再投资边界**：FY2026 PP&E 现金支出 307.12 亿美元，FY2027 前半年扣补助后的支出计划约 250 亿；现有现金、可交易投资和未使用 20 亿美元授信提供缓冲，但还需承担融资租赁、采购义务和保证金返还。10 月回购授权是可选资本使用，受协议条件约束，不是无条件资金承诺。【cite:O31】【cite:O96】【cite:O57】
- **判断强度**：当前节点进展 HIGH；未来单位成本及有效产量改善 MEDIUM；新增资本回报 Unknown。未取得维护/成长 capex、项目 NOPAT 或独立增量投入，不计算虚假项目 ROIC，也不假设供给可无限扩张。

## 四、关键变量传导链

### 综合判断
- 定价与合格出货共同决定收入，但价格、组合、数量的作用不能重复累加；利润还取决于成本、费用、税率与稀释股数。
- 多年协议可能改变收入及利润波动形态，合约数量、价格底线、信用保护和融资保证金是四种不同机制，不能互相替代。
- 制程和扩产存在“先投入、后合格产出”的时间差；营运资本及负债支付时点决定利润转现，客户保证金不提高 CFO 或简式 FCF。

## 五、潜在基本面因素缺口

以下均是供 C5 及后续预期研究检验的问题，不是已成立的差异、定价判断或正式 gap 对象。

### 1. 广谱涨价的可持续性来自终端需求，还是供给配置与客户备货？
- **关联**：D1；T1、T2。公司全年披露 ASP 大幅上升，MCBU 在比特出货减少的同时收入增加；这使“收入高增＝各终端数量高增”的假设不能成立。【cite:O57】
- **当前待核假设**：公司称 AI 需求超过行业供给，但本轮公司材料不能独立证明客户实际消耗、库存或竞争者可售供给。问题影响收入与 EPS 的持续性，而不只是行业叙事。
- **验证意义**：客户终端使用量、库存及采购节奏，与竞争者节点/产能及可比产品价格交叉证据，可确认涨价的需求/供给基础 → 修订“高售价可维持多久”的假设 → 仍不能精确证明美光单品利润或市场已如何反映。
- **Handoff**：C3 核实产业与客户证据；C5 将确认结果用于公司侧假设检验。不请求或等待 C2/O4。

### 2. Q1 收入继续增长但毛利指引略回落，是组合、爬坡成本还是价格兑现变化？
- **关联**：D1、D2、D4；T2、T4、T7。最新季度毛利率 86.8%，下一季度 GAAP 指引约 85.95%，与此同时收入中枢上升，产品认证与出货继续推进。【cite:O44】
- **当前张力**：里程碑进展与毛利率方向并非一一对应。Q4 毛利改善亦没有使营业利润率同比例上升，且有许可费用及研发/管理费用增加。【cite:O44】这不是已发生的价格下跌或执行失误。
- **验证意义**：同期间管理层量价/组合、量产良率、单位成本和费用桥，可确认毛利回落的具体来源 → 修订“高端采用可持续提高合并利润率”的假设 → 仍不能仅凭单季证明长期成本优势或单独算出 HBM 利润。
- **Handoff**：C5 取得公司季度说明及 GAAP/non-GAAP 对账；C3 核实客户平台与竞争产品变化。无需先假设卖方已过度乐观。

### 3. 战略合同利润底线适用于多少业务，是否能跨周期保持？
- **关联**：D3；T5、T6、T11。合同存在绑定数量、多数价格带及保证金安排；管理层预计底价毛利显著高于过去峰值，但没有披露合并业务覆盖比例。【cite:O57】【cite:O31】
- **当前张力**：强合同机制与未量化覆盖范围并存。保证金到账验证融资安排，不验证合约收入规模、毛利底线或客户未来全部履约；价格上限也有经济约束。
- **验证意义**：合约覆盖比特/收入、产品组合、期限、底价/顶价调整、成本承诺及实际交付披露，可确认保护范围和经济条件 → 修订“合并盈利波动显著下降”的假设 → 仍不能证明违约不会发生、所有非合同业务受保护或合同绝对毛利。
- **Handoff**：C5 细化合同覆盖和财务定义；客户信用与采购履约证据交 C3。不把非公开条款填成推定数值。

### 4. 2027 年瓶颈扩产能否在现金投入之后按期形成合格销售？
- **关联**：D2、D4；T3、T7—T9。节点量产占比已有进展，但新加坡封装、Idaho 首厂和铜锣商业出货仍是 2027 日历年计划；FY2027 前半年净资本投入约 250 亿美元、下半年更高。【cite:O88】【cite:O31】
- **当前张力**：支出时点有较具体计划，新增合格产量、爬坡损耗和项目增量回报没有对应量化。开工或初始晶圆不能确认瓶颈已解除。
- **验证意义**：设备安装、量产良率、先进封装与测试配套、客户认证、实际增量出货及项目支出，可确认商业爬坡而非仅物理完工 → 修订“投入能够及时转为有效供给”的假设 → 仍不能仅凭产能里程碑证明项目 ROIC 或全部需求会实现。
- **Handoff**：公司项目/财报证据交 C5，客户平台、供应链与行业新增供给交 C3。维护/成长 capex 未分离前不量化项目回报。

### 5. 当前利润转现中，负债支付时点带来的现金收益有多大可重复性？
- **关联**：D1、D4 的现金转换约束；T8、T10、T11。FY2026 CFO 高于净利润，同时应收占用 252.06 亿美元，其他非流动负债现金贡献 96.33 亿美元主要来自税款安排；保证金单独列融资现金流。【cite:O31】【cite:O44】
- **当前张力**：高 CFO 与显著应收占用、税费延后支付并存；公司 adjusted FCF 又包含补助。因此，强现金生成不自动等于所有增量都可重复或自由分配。
- **验证意义**：应收账龄及回款、Pillar Two 和其他税费支付计划、补助实收、保证金返还披露，可确认现金时点和占用结构 → 修订“利润增长可同比例转为持续可用现金”的假设 → 仍不能仅凭 CFO/净利润比例判定信用损失、违规会计或未来精确 FCF。
- **Handoff**：C5/后续公司财务预期研究；客户付款能力所需外部证据交 C3。授权回购与实际支付分开，不以授权额假设现金一定流出。
